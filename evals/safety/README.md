# Safety eval samples / 安全評価サンプル (data/evals/safety)

**This is test data. It is not shown to players and does not go into character or narrator prompts or into memory.** It is only used as a reference for the backend safety classifier (S-4 `--classify-only`).

**ここはテストデータです。プレイヤーには見せず、人物や語り手のプロンプトにも記憶にも入れません。** バックエンドの安全分類器の照合にのみ使います（S-4 の `--classify-only`）。

| File / ファイル | Contents / 内容 |
|---|---|
| `s4_selfharm.jsonl` | Self-harm signal samples (S-069, supplementing S-043 and S-057). Generated by `../gen_selfharm.py`; do not edit by hand. For fields and thresholds see "Self-harm signal samples" in `../README.md`. / 自傷シグナルのサンプル（S-069、S-043・S-057 を補う）。`../gen_selfharm.py` で生成、手で編集しない。フィールドと基準は `../README.md`「自傷信号样本」を参照。 |
| `s4_selfharm_holdout.jsonl` | 25 holdout validation samples (PM, backend, 2026-10-07). Generated by `../gen_selfharm_holdout.py`. **Used only to validate the finalized classifier v3; never use it to tune prompts.** S-072 (2026-10-07) already validated v3 with it, a one-time use, so it was moved into the repo; the next classifier version needs new holdout samples. / 留保検証サンプル 25 件（PM、バックエンド 2026-10-07）。`../gen_selfharm_holdout.py` で生成。**確定済みの分類器 v3 の検証にのみ使い、プロンプトの修正には使わない。** S-072（2026-10-07）が v3 の検証に一度使用したため、リポジトリに移した。次版の分類器には新しい留保サンプルを別途作成する。 |

Writing rules: real signals describe only the mood, with no method, tool, place, or time, and no glorification (stating a decision without time or means is allowed); lines inside the story are written in the modern colloquial speech the player would actually use in that scene. UX has reviewed them (`ux/reviews/selfharm-samples.md`).

書き方：実際のシグナルは気持ちだけを書き、方法・道具・場所・時間は一切書かず、美化しない（時間や手段を伴わない決意の表明は可）。物語内の台詞は、その場面でプレイヤーが実際に言う現代の口語で書く。UX レビュー済み（`ux/reviews/selfharm-samples.md`）。

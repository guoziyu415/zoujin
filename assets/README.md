# assets

Art assets. Owned by frontend; UX sets the standards.
アート資産。フロントエンドが担当し、UX が基準を定める。

- `pipeline/`: scripts for modeling, decimation, compression, and checking (from the A-0 pilot; Blender scripts and Node scripts).
  モデリング、ポリゴン削減、圧縮、検査のスクリプト（A-0 パイロット由来。Blender スクリプトと Node スクリプト）。
- `manifest/`: download manifest for CC0 source materials (URLs and sha256). Source materials are not kept in the repo; scripts download and verify them per the manifest.
  CC0 ソース素材のダウンロード一覧（URL と sha256）。ソース素材はリポジトリに入れず、スクリプトが一覧に従ってダウンロードし照合する。
- `budgets.json`: budgets for assets and bundles (frontend-design 10.1, 10.6.2, D-019); CI goes red when exceeded.
  資産とバンドルの予算（frontend-design 10.1、10.6.2、D-019）。超過すると CI が赤になる。
- Hand-edited `.blend` files and generated `glb`, `ktx2`, and textures go through Git LFS (see `.gitattributes`).
  手作業で編集した `.blend` と、生成された `glb`、`ktx2`、テクスチャは Git LFS で管理する（`.gitattributes` 参照）。
- Prerecorded audio `voice/<book>/` (B-6: `.m4a` files generated by `zoujin-voice` and the voice manifest `voices.json`) goes through plain git, not LFS (S-084: the project thread's container cannot push LFS); each file is well under 1 MB.
  録音済み音声 `voice/<book>/`（B-6：`zoujin-voice` が生成した `.m4a` と音声一覧 `voices.json`）は LFS ではなく通常の git で管理する（S-084：プロジェクトスレッドのコンテナは LFS をプッシュできない）。各ファイルは 1 MB を大きく下回る。

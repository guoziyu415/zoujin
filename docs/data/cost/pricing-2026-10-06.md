### Billing mechanics, quoted from official pages

**Context accumulates and is re-billed every turn.** [VTX-GENAI], Live API Billing Details, says:
> "Users are charged for all tokens present in the Session Context Window during that turn… Tokens from past turns are re-processed and billed in every new turn, up to the configured context window size limit."

A "turn" is one user input plus the model's response.

**Transcription.** When audio-to-text transcription is on, the transcript text tokens are billed at the text output rate ($4.50/1M for 3.8 Live). Source: [VTX-GENAI].

**Thinking tokens.** These are billed as text output. The GAPI output row reads "Output price (including thinking tokens)".

**Proactive Audio mode.** "Input tokens are charged while LiveAPI is listening. Output tokens are only charged when the API responds." Source: [VTX-GENAI], Gemini 2.5 section.

**Context window compression (sliding window).** This is what caps the accumulated, re-billed context.
- Source: https://ai.google.dev/gemini-api/docs/live-session (last updated 2026-09-15) and https://ai.google.dev/api/live (last updated 2026-09-04).
- `contextWindowCompression: { slidingWindow: {} }` turns it on.
- `triggerTokens` defaults to **80% of the model's context window limit**. For 3.8 Live that is about 105k tokens *(derived from the 131,072 input limit)*.
- `SlidingWindow.targetTokens` defaults to **trigger_tokens/2**.
- Setting a low `triggerTokens` is the main lever on per-turn input cost.

**Session limits.** Source: https://ai.google.dev/gemini-api/docs/live-session (2026-09-15).
- "Without compression, audio-only sessions are limited to 15 minutes, and audio-video sessions are limited to 2 minutes."
- A single connection lasts about 10 minutes.
- Session-resumption tokens are valid for 2 hours after the session ends.

**Context caching.** The Live API has no cached-input price on [VTX-GENAI] (N/A) and no caching row on [GAPI]. Explicit context caching should be treated as **not applicable** to Live.

**Audio tokens/sec differs by API.**
- Live API: **25 tok/s** (Vertex footnote). The GAPI per-minute equivalents are consistent with 25.
- Non-Live audio understanding via generateContent: **32 tok/s** ("32 tokens per second of audio (1 minute = 1,920 tokens)"). Source: https://ai.google.dev/gemini-api/docs/audio (last updated 2026-09-23).
- Gemini Omni Flash: 32 tokens per audio second.
- Gemini-TTS output: 25 tok/s.

- **Free tier.** The Gemini API free tier is available for the 3.x Flash and Flash-Lite models, but not for 3.1 Pro Preview. Source: [GAPI].
- **Gemini Deep Research Agent.** Not needed for this app; listed for completeness. Standard is $2 input / $12 output / $0.20 cached. Source: [VTX-GENAI].

## Caveats

1. **Preview vs GA**
   - Stable/GA: Gemini 3.8 Live, 3.8 Live Extended Thinking, 3.8 Flash, 3.5 Flash-Lite, 3.1 Flash-Lite, and Nano Banana 2 / 2 Lite / Pro (on GAPI).
   - Preview: Gemini 3.1 Pro (`gemini-3.1-pro-preview`), 3.1 Flash Live (legacy), Veo 3.1 and 3.1 Lite (on GAPI), Gemini Omni Flash, and Gemini 3.8 Flash TTS (labelled Preview on the Cloud TTS page).
   - Gemini 2.5 models are "Limited Access", available only to past users. Prices for preview models can change.

2. **Time-limited promo pricing.** Gemini 3.8/3.7/3.6 Flash and 3.8 Flash(-Lite) TTS are at 50% intro prices only **through 2026-12-31**, delivered as 50% credits back. Model 2027 costs at the higher list price.

3. **Regional pricing**
   - On Vertex, GA Gemini 3+ models called via a **non-global (regional, e.g. Tokyo) endpoint cost +10%** from 2026-07-01.
   - Gemini 3.8 Live is listed only with region "Non-global" at $0.75/$3/$12. I could not confirm whether 3.8 Live is served in asia-northeast1: the Agent Platform docs pages (locations and model page) did not render their body text through the fetch tool.
   - Cloud Run Tokyo is Tier 1, the same as us-central1.
   - Firestore and Cloud SQL Tokyo cost about 20–30% more than us-central1.

4. **Inconsistent data on the official pages**
   - **Cloud SQL Tokyo shared-core:** the monthly and hourly views disagree ($10.22/mo vs $0.0122/h for db-f1-micro). Tokyo SSD storage also disagrees ($0.221/mo vs the us-central1 hourly value).
   - **Firestore Tokyo stored data:** shown as $0.115/GiB-month, which is the same number as the Tokyo write price. Tokyo PITR is shown at $0.195, and several other regions also show storage equal to their write price. This looks like a page error. Storage is negligible per session either way.
   - **Veo units:** the Vertex Veo table says "/ 1 count", but billing is per second.
   - **Gemini 3 Flash Preview:** the Vertex standard table omits the output row; I took $3.00 from GAPI.
   - **Recommendation:** confirm the Tokyo Cloud SQL and Firestore figures in the Pricing Calculator or the Cloud Billing SKU catalog. I could not query the SKU catalog because gcloud has no credentials here.

5. **Free tiers**
   - Gemini API free tier: Live and Flash models are free of charge, but data is used to improve products and rate limits are low. This is not suitable for production with end users.
   - Cloud Run: 180k–240k vCPU-s and 360k–450k GiB-s per month, plus 2M requests on request-based billing.
   - Firestore: 50k reads, 20k writes and 20k deletes per day, plus 1 GiB, on the default database only.
   - Agent Platform: 50 vCPU-h, 100 GiB-h and 1 GiB-month storage per month.
   - Cloud TTS Chirp 3 HD: 1M characters per month.
   - STT V1: 60 minutes per month.
   - Grounding: 5,000 queries per month.

6. **Live API cost drivers that the list prices hide**
   - Re-billing of accumulated context on every turn, which can make input cost grow roughly quadratically with session length until sliding-window compression caps it.
   - Proactive Audio bills input while listening.
   - Transcripts are billed at the text output rate.
   - Thinking tokens are billed at the text output rate.
   - **Not documented:** the modality (and therefore the rate) at which re-processed past audio is billed. The Vertex page says only "all tokens present in the Session Context Window". Assume past audio is re-billed at the $3/1M audio input rate.

7. **Memory Bank changed pricing model on 2026-09-01.** Older "per memory stored / per retrieval" figures from blogs are obsolete.

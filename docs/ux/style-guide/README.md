- 底色不低于 sRGB 30、不高于 240（太黑太白在 PBR 下都不真实）。
- **緋色要靠饱和度跳出来**（art-direction 6）：R1 必须是画面里饱和度最高的颜色。除緋色以外不用红；赭 O1 偏黄褐，不能被看成红。
- 人物的衣服要和石灰岩分得开：广场的地面和墙是带蜜色的白（plaza-materials.md），所以人物身上**面积最大的那块颜色要比墙暗或者比墙饱和**。梅洛斯的赭、旅人的海色、老爺的灰褐都是按这个选的：三个人的主色一黄褐、一蓝、一灰，色相也分开。村子里同样：灰泥墙偏土黄、麦子金黄，所以妹的褐、牧童的深胡桃都比它们暗。
- **三个玩家身份各有一个「自己的颜色」**，放在面积最大的那件上，和緋色腰带配在一起：旅人海色 B1、弟子土色 U1、牧童深胡桃 N3。
- 番红花黄 S1 的饱和度比緋低，但新娘的面积大、又在真昼：婚礼画面出来后看一眼緋还是不是最跳的（sister.md）。

### 皮肤

| 人物 | 底色 sRGB | 说明 |
|---|---|---|
| メロス | `#8A5A3C` | 晒得黝黑的牧人（art-direction 5.1）。露在外面的右肩和手臂一样黑 |
| 町の老爺 | `#A07A5F` | 晒过很多年、发灰，皱纹靠法线（9.4） |
| 旅人 | `#A47B5F` | 只看得见手、小腿和脖子后面 |

- 要有血色和透光感，不做毛孔、汗毛、油光（5.1）。
- 不做血（9.4）。原作里梅洛斯「口から血が噴き出た」不演。

### 磨损和脏

- 衣服的下摆有一圈 10〜15 cm 的尘土色，越往下越重；脚和小腿也有尘土。
- 布的边缘起毛，膝盖、手肘、肩上被晒褪色。
- 脏和磨损画在颜色图里，**两档用同一张源图**，强机只是更清楚（9.1 第 3 条）。

### 面数和贴图（引用 art-direction 9.2，不另定）

- 对话版：档 B 2〜3 万面、强机 4 万面；材质 4〜5 个（皮肤、眼、发片、衣服、牙）。
- **所有衣服、鞋、带子和随身的东西共用「衣服」一个材质、一张 1024 的图**（两档都是 1024，9.2）。所以每个人物的服装表都写了这张图上各部分大概分多少面积。
- 走动版：8k 面，2 个材质，所有部件都在，轮廓一样。
- 手里拿的道具（杖、水袋）另算：探索里 512，对话时拿在手里的 1024（9.2）。

### 轮廓

探索镜头离人约 15.5 m、俯角约 29°（ux-design 6.3：距离 13.5、高 7.6），人物在手机上只有 40〜80 px 高。每个人物要有**三样在这个大小下认得出的东西**，各自的服装表里写了。验收：

1. 在 F-2b 的广场里，用探索镜头从前、后、左、右四个方向看，把人物渲成纯黑剪影，缩到 60 px 高。
2. 三个人物两两之间、和刑场群众（art-direction 5.5）之间，一眼分得开。
3. 不对的话先改轮廓（帽子、背的东西、姿势），不靠颜色。

[silhouettes.svg](characters/silhouettes.svg) 是平视的示意，真正的测试用游戏里的镜头。

### 动起来的部分

不在手机上做布料模拟（由前端定），但这些地方要动，用几根骨骼带：

- 下摆：走路和跑步时摆动。
- 带子的尾巴、外套的折边：风里轻轻动（art-direction 7「风」）。
- 背的东西、水袋：跟着步子晃。

两档的动作一样（9.2）。

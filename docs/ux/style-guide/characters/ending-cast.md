# 切片结局里的其余人物

切片在三日目日没的广场演一个简化的结局（S-050）。PM 2026-10-10 在切片配置里定了结局里出场的人（S-077）：セリヌンティウス、王、警吏、群众、緋のマントの少女。这一页写他们在切片里要的样子，**先按走动版的精度**（8k 面，2 个材质，art-direction 9.2）。哪些镜头离得近、要更高精度，UX 和前端在项目文件夹 `ux/slice/ending-shots.md` 里定，定了以后写进 ux-design。

M3 里セリヌンティウス和王会成为可以对话的人物，到时候各自补完整的服装表（对话版、脸、口型）。这里先定轮廓、颜色和在结局里的样子，M3 照这个往上加，不推翻。

共用的规则（尺寸、色表、磨损、轮廓验收）见 [README](../README.md)。图：[ending-cast.svg](ending-cast.svg)（正面的颜色、60 px 剪影、在人群里找得到吗）。

**画出来以后看到的一件事**：从群众背后看密的人群，逆光剪影里**老爺几乎找不到**：兜帽和别的女人一样，驼背和拐杖被前后的人挡住。旅人靠帽檐、警吏靠锥形盔和矛、王靠身高和两边的警吏，都还认得出。所以结局里老爺不能埋在人群中间：站在**前排或人群边上**（ux-design 11.1 的 `in-crowd` 本来就要求前排），玩家选了「老爺の家に身を寄せる」时就站在玩家旁边。镜头从人群背后拍时，他要在画面里人群的边上。

## 一眼分得开

结局在逆光和暮色里演，脸多半看不清（art-direction 5.3）。每个人靠下面这些在剪影里分开：

| 人物 | 剪影里认他的东西 | 和谁最容易混 | 怎么分开 |
|---|---|---|---|
| メロス（结局版） | 几乎光着上身，从城门一路跑进来 | 群众里光膀子的工人 | 群众里不放光着上身的人 |
| セリヌンティウス | 柱上被绑的人；被放下后，宽肩、短胡子 | — | 位置就够了 |
| 王 | 最高，站得笔直，长袍到脚踝，头上一道细的金带 | 群众里穿长袍的老人 | 王的长袍颜色最深；身边跟两个警吏 |
| 警吏 | 锥形的盔，竖着的矛 | — | 群众里不放戴锥形帽、拿长杆的人 |
| 緋のマントの少女 | 个子小，头纱，怀里抱着一团东西 | 群众里的女人 | 递出斗篷前没法分，也不用分：她就该从人群里突然走出来 |
| 町の老爺 | 驼背、兜帽、拐杖（old-man.md） | 群众里的老人 | 群众里不放「盖头 + 拐杖」的人 |
| 旅人（玩家） | 宽檐帽、海色、緋色腰带（traveler.md） | — | 群众里不放宽檐帽 |

## セリヌンティウス

> 竹馬の友、セリヌンティウスは、深夜、王城に召された。……セリヌンティウスは、縄打たれた。

梅洛斯的竹马之友，在城里当石匠，和梅洛斯同岁（二十出头）。三天前的深夜被叫进王城当人质，一直被关着，今天被押到刑场。

| 项 | 要求 |
|---|---|
| 身高、体型 | 1.72 m，7.25 头身。**所有人物里最宽**：肩宽、胳膊粗，石匠的身体。和梅洛斯并排时，一个瘦长、一个宽厚 |
| 脸 | 平静，原作里他「無言で首肯き」。短而整齐的深褐色胡子（约 1 cm），**上唇剪开**，M3 要读口型 |
| 头发 | 深褐，短，比梅洛斯直 |
| 皮肤 | `#9A6A4C`，比梅洛斯浅一点：在城里的石场干活，不是放羊 |
| 衣服 | 石匠的短衣（exomis），**和梅洛斯相反，露左肩**，未染的羊毛 W0 洗得发灰，身上沾着白色的石粉。**结局里没有皮围裙**：三天前深夜从工房被叫走，围裙留在了工房（M3 的工房场景里，围裙挂在工房墙上〔推断〕） |
| 被绑的样子 | 麻绳，**双手绑在身后**，绳子绕过胸口和柱子，往上吊。双臂不张开：只有一根竖柱，不做成十字架的样子（art-direction 4.1） |
| 三天的痕迹 | 衣服皱、脏，胡子没刮所以比平时长一点，脸色暗。不做伤（他没挨打，原作没写） |
| 被放下以后 | 绳子解开，手腕上留一圈红印（颜色图上的深红褐色，不画血）。站在磔台上和梅洛斯互打、拥抱 |

## 王ディオニス

> その王の顔は蒼白で、眉間の皺は、刻み込まれたように深かった。

| 项 | 要求 |
|---|---|
| 身高、体型 | 1.82 m，**所有人物里最高**，7.5 头身。肩宽但瘦，站得笔直，背从不弯 |
| 年龄 | 五十岁左右〔推断〕。原作没写年龄，按「暴君」做了很多年、杀了亲人的人来定 |
| 脸 | **蒼白**（皮肤 `#B89A86`，所有人物里最浅、最冷）。眉间两道很深的竖纹（法线），眼窝深 |
| 胡子和头发 | 深灰夹白的短胡子，修得整齐，**上唇剪开**（M3 要读口型）。头发短，向后梳 |
| 衣服 | 长衣（chiton）到脚踝，深灰 `#4A4744`；外面一件**厚重的深紫长袍**（himation，骨螺紫）。深紫 P1 `#46304A`，是除緋色以外饱和度最高的颜色，但比緋暗得多，不能被看成红（art-direction 5.4） |
| 头带 | 一道细的金头带（diadem），宽约 1.5 cm。王出场时太阳已经落了，刑场的火把照到它时会亮一下，远处靠这个和身高认 |
| 鞋 | 深色皮鞋，盖住脚面（不是凉鞋），和平民分开 |
| 在结局里 | 原作「群衆の背後から二人の様を、まじまじと見つめていた」，然后「静かに二人に近づき」。所以王先站在**群众背后**（西侧，城门这一边），不是在王城台阶上，然后穿过让开的人群走向磔台〔ux-design 11.1 的 `approaching`〕。身边跟两个警吏 |
| 动作 | 走得慢、稳，走近时双手垂下、不摆架子。原作「顔をあからめて」：脸红在这个距离看不见，交给叙事 |

## 警吏（巡邏・刑吏）

| 项 | 要求 |
|---|---|
| 做法 | 和群众共用低模（art-direction 5.5），加盔、矛、外套 |
| 盔 | **锥形的盔**（pilos 型），旧青铜，哑光发暗。所有人物里只有警吏戴，剪影里一眼认出 |
| 矛 | 约 2.4 m，木杆、铁矛头。竖着拿，矛头高过所有人的头 |
| 衣服 | 短衣到膝上，深胡桃褐 N1；外面一件短斗篷，未染的深色羊毛。**不用红斗篷**（斯巴达式的红斗篷最容易混进来，会抢緋色） |
| 刑吏 | 刑场上拉绳子的两三个人：同一套，不戴盔、不拿矛，袖子卷起来 |
| 城门那一幕 | 第一幕夜里在王城门口抓梅洛斯、拦旅人的就是他们（项目文件夹 `ux/slice/act1-end-and-gate.md`）。夜里身边有火把 |

## 刑场的群众

按 art-direction 5.5：3〜4 种体型 × 3 种服装 × 颜色微调，动作错开时间。补充：

- **颜色**只从色表里挑：未染的亚麻 L0、未染的羊毛 W0、胡桃褐 N1、褪色的菘蓝 B1、橄榄 G1、旧的灰褐 A1。**不用緋色和其他红**，赭色也别用（那是梅洛斯的）。
- **服装**三种：
  1. 男，长衣加外袍（最多）；
  2. 女，长衣，外袍拉起来盖住头（不拿拐杖）；
  3. 干活的男人，短衣，戴低的圆毡帽（不是锥形的，锥形归警吏）。**短衣要两肩都盖住**，不露右肩（那是梅洛斯的）。
- **不放**：宽檐帽（旅人的）、「盖头 + 拐杖」（老爺的）、锥形帽和长杆（警吏的）、光着上身的人（结局的梅洛斯）。
- 头上要有变化（光头、头纱、毡帽），因为群众是背对镜头、逆光看的，剪影里最先看到的是头和肩。

## 緋のマントの少女

> ひとりの少女が、緋のマントをメロスに捧げた。

| 项 | 要求 |
|---|---|
| 做法 | 群众女装的一个变体，个子小（约 1.50 m） |
| 年龄 | 十几岁〔推断〕。原作只说「少女」「可愛い娘さん」 |
| 衣服 | 浅色的长衣 L0，头纱（未染的薄亚麻，比老爺的兜帽轻、透光） |
| 斗篷 | 緋のマント（melos.md）**叠起来抱在怀里，用她自己的外袍盖住**，递出去时才展开。在那之前群众里看不到緋色：緋色只给三样东西（art-direction 6），斗篷要在那一刻才跳出来 |
| 动作 | 从前排走出来，双手托着展开的斗篷递给梅洛斯，然后退回人群 |

## 骨骼（走动版）

- 王和セリヌンティウス：标准人形骨骼加下摆 2〜4 根。脸先只要下巴一根骨骼（大声说话、哭的时候张嘴）〔前端定做法〕；完整的表情形变等 M3 的对话版。
- 警吏的矛、王的头带是刚体。少女的斗篷展开时要能动，至少 4 根骨骼。

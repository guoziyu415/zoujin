# 花婿

> 婿の牧人も頑強であった。……花婿は揉み手して、てれていた。

村里一个「律気」的年轻牧人，梅洛斯妹妹的结婚对象（`char.groom`）。第三幕（村子）**对话版**。声音 D-025：Sadachbia。

共用的规则见 [README](../README.md)。图：[m3-cast.svg](m3-cast.svg)。

## 一眼认得出的三样（探索镜头，60 px）

1. **到膝盖的厚橄榄色斗篷**：在右肩用别针别住，把上身和两臂裹在里面，人看起来比实际宽。村里只有他披这么厚的。
2. **圆毡帽**：低的圆顶，没有帽檐（不是锥形：锥形是城里警吏的；不是宽檐：宽檐是旅人的，收麦的人是草帽）。
3. **结实**：肩宽、腿粗，站得稳。待机动作是**搓手**（「揉み手」）。

婚礼那天不戴帽、不披斗篷，换成桃金娘的花环和搭在左肩的橄榄色外袍。

## 对话版

- art-direction 9.2 的对话版。
- **搓手**是他的标志动作，对话的待机里要有：两手在胸前或腹前慢慢搓，说到不好意思的地方加快一点。和结局的专属动作一起排（前端）。
- 斗篷裹着左臂：说话时只用右手比划。

## 动起来的部分

- 斗篷下摆 3 根骨骼。外袍（婚礼）垂下的一角 2 根。
- 小刀是刚体，跟腰带。

## 验收

1. 60 px 剪影里，在村子里和梅洛斯、收麦的人分得开：宽、厚斗篷、圆帽（m3-cast.svg 下方「村子」）。
2. 婚礼时和新娘站在一起，新娘的黄是两人里最显眼的。
3. 对话时搓手的动作读得出来，不像在发抖。

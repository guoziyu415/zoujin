# 玩家・旅人

> はじめてこの市に来た。誰も、あなたを知らない。

玩家自己。人物称呼「旅の方」，不起名字（ux-design 5.1）。

## 看得见的只有背影

- 探索时镜头在身后上方（ux-design 6.3），对话时只露肩膀在左下前景。所以**背影是这个人物的正面**：最好看、最认得出的东西都放在背后和侧后方。
- **玩家的脸不出现在读得清的大小。** 探索镜头可以转到正面，但那时人物只有 40〜80 px，脸被帽檐的影子盖住。镜头不在玩家面前 6 m 以内停下来；结局里柱上的你也从背后拍（ux-design 11.4 B）。
- **不分男女。** 身份卡和人物的称呼都不分（「旅の方」），玩家用自己的声音说话。所以身体按中等偏瘦、不强调男女的样子做：头发收在帽子里，长衣过膝，外套搭在臂上，没有胡子。〔UX 定，PM 有不同意见再改〕

## 一眼认得出的三样（探索镜头，60 px）

1. **宽檐帽**：从后上方看是一个大圆盘，所有人物里只有他有。
2. **緋色腰带和垂下的带尾**：背后看是一道横的红，左侧垂下两条。
3. **斜挎的水袋带**：从左肩斜到右胯，水袋在右后方。

## 身体

| 项 | 要求 |
|---|---|
| 身高、体型 | 1.68 m，7.25 头身，中等偏瘦 |
| 姿势 | 自然站直，肩放松。玩家没操作时，待机动作是看看四周（这是个初来的人） |
| 皮肤 | `#A47B5F`，只看得见手、前臂、小腿和后颈 |
| 头发 | 收在帽子里，后颈露一点短发 |

- 尘土：下摆和鞋，比梅洛斯少（他今天没走十里）。
- 緋色只有腰带一处（art-direction 6）。帽子、外套、水袋都不加红。

## 对话镜头

- 越肩镜头里玩家只露肩膀（ux-design 6.3），**帽檐不能进画面挡住对方的脸**。前端摆镜头时按帽檐的宽度留出余量。
- 左下前景里露出的是海色的肩，海色是玩家自己的颜色。搭在左臂上的浅色外套可以露一角。

## 以后要的（不在切片里）

- 外套披上的样子（夜里、下雨），以及披上时腰带怎么露出来：等有夜景和雨景的身份再定。
- 石屋の弟子、村の牧童两个身份：M3。

## 动起来的部分

- 腰带尾巴每条 2 根骨骼，跟风和步子动。
- 外套的垂边 2 根骨骼。
- 水袋 1 根骨骼。
- 帽子是刚体，跟头。

## 验收

1. 60 px 剪影里，从背后和侧后方一眼认得出（上面三样），和梅洛斯、老爺、群众分得开。
2. 日没时整个画面偏暖，腰带仍然是画面里饱和度最高的颜色（art-direction 6，S7 的日没画面专门看）。
3. 对话镜头里帽檐不挡对方的脸。
4. 转到正面看时，脸在帽檐的影子里，没有能看清的五官。

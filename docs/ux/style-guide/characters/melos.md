# メロス

> メロスは、村の牧人である。笛を吹き、羊と遊んで暮して来た。けれども邪悪に対しては、人一倍に敏感であった。

单纯、急躁、正直的年轻牧人。今天天没亮就从十里外的村子走来，给妹妹买婚礼的衣服和酒席的东西。

## 一眼认得出的三样（探索镜头，60 px）

1. **前倾的瘦长身体**，走路也带点往前冲的劲。
2. **露出的右肩和右臂**：短衣只系在左肩，领口从左肩斜到右腋下。左右不对称是他和所有人最大的区别。
3. **第一幕背上一个浅色的包袱**（背后看是一个圆鼓鼓的浅色块）。

结局时没有包袱，衣服几乎撕光，正面的剪影就是一个普通的人（silhouettes.svg）。那时认他靠位置和动作：从城门冲进来、一路跑向磔の柱的只有他（art-direction 4.1 城门到柱子的那条直线）。

## 身体和脸

| 项 | 要求 |
|---|---|
| 年龄 | 二十出头 |
| 身高、体型 | 1.75 m，7.5 头身。瘦长，手脚长，有干活练出来的肌肉，不鼓 |
| 姿势 | 站着时重心略向前，肩不缩。生气时下巴往前 |
| 皮肤 | 晒得黝黑（`#8A5A3C`），手背、脖子、露出的右肩一样黑 |
| 脸 | 直率、藏不住事。眉毛浓而平直，眉的三种动作（平、皱、扬）是他表情的主力（art-direction 5.1 第 4 条）。眼睛清楚，高光不能被眉骨的影子吃掉 |
| 胡子 | **不留胡子**，最多一层很短的胡茬（画在颜色图里）。嘴的形状要看得清，口型是 5.1 第 3 条 |
| 头发 | 深褐近黑，短而卷，约 3〜4 cm，看得见耳朵。档 B 可以用贴图的头皮加少量发片 |

## 第一幕：进城（切片要的）

> メロスは、単純な男であった。買い物を、背負ったままで、のそのそ王城にはいって行った。

| # | 部件 | 材料和颜色 | 做法 | 在 1024 图上约占 |
|---|---|---|---|---|
| ① | 短衣（exomis） | 粗羊毛，赭 O1 `#A5733F`，洗得发旧 | 一块约 1.6 × 1.0 m 的布裹住身体，**只在左肩打结**，右肩和右臂露在外面。领口从左肩斜到右腋下。腰上系住后，上面鼓出 5〜8 cm 的一圈。下摆在膝盖上方约 12 cm（大腿中间偏下），右侧从胯下开衩，方便跑 | 45% |
| ② | 腰绳 | 未染的羊毛搓的绳，W0 `#CBBDA3`，粗约 1 cm | 在左前方打结，绳头垂约 15 cm | 4% |
| ③ | 凉鞋 | 旧皮革 K1 `#6E4A2E` | 一层皮底，夹脚趾的带子加一圈脚踝带。脚和小腿上有一路走来的尘土 | 10% |
| ④ | 包袱 | 未染的羊毛布 W0，四角打结 | 一块约 1.1 m 见方的布包着买的东西（新娘的衣服、酒席的东西），在胸前斜着打结：一角过右肩、一角过左腋下。背后看是约 55 × 40 × 22 cm 的圆鼓鼓的一包，**从正面也要从左右两边露出一点**（views.svg 正视图）。不透出里面的东西 | 15% |
| ⑤ | 短剑 | 铁刃约 25 cm，木柄 | **藏在①腰上鼓出的那圈布里，平时看不见**（原文「メロスの懐中からは短剣が出て来た」）。只在王城被搜身那一下出现，做成单独的道具（512），不长在衣服上 | 道具另算 |

- 尘土：下摆一圈、膝盖以下、脚。走了一天，但没有泥。
- 汗：额头和脖子可以颜色略深，不做油光。
- 包袱在进王城被捕以后仍然带着（他之后带着新娘的衣服回村，「綺麗な衣裳も買って来た」）。

## 结局：日没冲进刑场（切片要的）

> メロスは、いまは、ほとんど全裸体であった。

演成衣服撕得几乎不剩，不演裸体（art-direction 5.4）。

| # | 部件 | 和第一幕比 |
|---|---|---|
| ① | 短衣 | **腰以上撕掉了**，上身和双臂全露。腰绳以下剩一圈破布，裹到大腿中间，右边撕得更短，边是参差的破口。颜色更脏、褪得更白 |
| ② | 腰绳 | 还在，系法一样 |
| ③ | 凉鞋 | 还在，带子上糊满干了的尘土 |
| ④ | 包袱 | 没有 |
| ⑤ | 短剑 | 没有（第一幕就被没收了） |

- **擦伤**：两个膝盖、两条小腿前面、右前臂、左肩。用比皮肤深的红褐色块画在颜色图里，**不画成鲜红、不画血**。块要大到在对话镜头的档 B 上读得出来（art-direction 9.1 第 3 条：强机不能多出档 B 看不到的伤）。
- **泥**：小腿上有过河留下的、干成灰褐的泥（`#8C8270` 左右），膝盖以上没有。
- **尘土**：全身一层，头发里也有。
- 头发乱，被汗贴住额头。

### 緋のマント（结局里赶上了的那几种）

> ひとりの少女が、緋のマントをメロスに捧げた。

| 项 | 要求 |
|---|---|
| 是什么 | 一块茜草染的羊毛外袍，约 2.4 × 1.2 m |
| 颜色 | 緋 R1 `#8E271C`，**和玩家的腰带同一种染料、同一个底色**。art-direction 6：结局时斗篷把玩家的腰带和界面的因果线连起来 |
| 怎么穿 | 少女递给他以后，披上双肩、在胸前裹住，垂到膝盖 |
| 只出现在 | 结局演出里少女把它递过去之后。世界里别处没有这块布 |
| 材质 | 单独的道具，1024（结局演出里离镜头近） |

## 以后要的（不在切片里）

- **王城里被绑**：双手在身前用麻绳捆住（第一幕后半，王座之间）。
- **第三幕（村子）**：同一件短衣，没有包袱；婚礼时可以加一条干净的腰带〔推断〕。
- **第四幕路上**：从雨中出发到冲进刑场之间，衣服一步步变破（过河、和山贼打）。分几级由归途的场景设计定。
- 牧人的笛子（「笛を吹き」）：可以插在腰绳上，作为一个小细节〔可选，P1〕。

## 动起来的部分

- 短衣下摆 4〜6 根骨骼：跑的时候甩得开，结局那圈破布也用同一组骨骼。
- 包袱 1 根骨骼，跟着步子上下晃。
- 绳头不用骨骼。

## 验收（在 A-0 的测试页和 F-2b 的广场里看）

1. 第一幕：60 px 剪影里，从背后、正面、右侧都认得出是他（上面三样）。
2. 对话镜头的档 B 上，露出的右肩、领口的斜线、腰上鼓出的那圈读得出来。
3. 17:30 的逆光下，赭色短衣和王城的金色墙分得开；轮廓有一圈亮边（art-direction 3.2）。
4. 结局版：擦伤在档 B 上读得出来，没有鲜红；整体不会被看成裸体。
5. 档 B 和强机并排时颜色一样，强机只是更清楚（9.5）。

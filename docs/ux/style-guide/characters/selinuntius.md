# セリヌンティウス（对话版）

> セリヌンティウスは無言で首肯き、メロスをひしと抱きしめた。

M3 里セリヌンティウス成为可以对话的人物（`char.selinuntius`，声音 D-025：Iapetus）。石屋の弟子开局就在他的工房，守人质的玩家三天都在他身边（castle.md 北柱廊 `hostage-column`）。

**轮廓、颜色、刑场上被绑和放下以后的样子照 [ending-cast.md](ending-cast.md)「セリヌンティウス」**，这里加对话版要的脸，和刑场以前的三个样子。共用规则见 [README](../README.md)。图：[m3-cast.svg](m3-cast.svg)（「工房」里系着围裙的他）。

## 脸

| 项 | 要求 |
|---|---|
| 脸 | 宽脸、方下巴，平静。原作里他话少（「無言で首肯き」「メロスは来ます、とだけ答え」），所以**表情要小**：说话时眉和嘴的动作都比梅洛斯小一半 |
| 胡子 | 短而整齐的深褐胡子，约 1 cm，**上唇剪开**（ending-cast.md）。三天以后长一点（下面） |
| 眼 | 稳，看人时不躲。这是他和慌张的フィロストラトス、躲着人的王最大的不同 |

**表情预设**（52 个形变 + 元音口型）：

| 预设 | 什么时候 | 怎么做 |
|---|---|---|
| 首肯く | 他最常用的回答 | 下巴慢慢点一下，眼睛不离开对方，嘴闭着。和头部的骨骼动作一起 |
| 信じている | 「メロスは来ます」 | 眉平，嘴角放松，眼神稳。不笑 |
| 一瞬の疑い | 三日目 16:00（beat.s2，柱廊里） | 眼神往下、往旁边移开一下，眉头轻轻一皱，马上回来。**一闪就过**，只给在他身边的人看见（castle.md 第 0 节） |
| 憔悴 | 三日目 | 眼睑重一点，嘴角往下一点（叠加在别的预设上） |

## 刑场以前的三个样子

| 样子 | 什么时候、在哪 | 和 ending-cast.md 的结局版比 |
|---|---|---|
| **工房** | 一日目 17:30 前后（弟子开局，约束の日）。工房 | 同一件露左肩的短衣，**系着皮围裙**（深褐皮，从胸到膝下，背后两条带交叉），袖子卷起来，手上、围裙上满是石粉。手里拿着凿子或木槌。围裙被叫走时留在工房墙上（ending-cast.md） |
| **被召来** | 一日目 23:30（beat.06）。王座之间 | 没有围裙，石粉还在。深夜从家里被叫出来，肩上披一块未染的羊毛 W0 的外袍〔推断：夜里出门〕，进王座之间时被拿掉。和梅洛斯相拥以后**双手在身前被麻绳捆住** |
| **柱廊的三天** | 一日目深夜〜三日目傍晚（被押去刑场前）。中庭北柱廊，第二排的柱子 | 背靠柱子坐在地上，双手在身前捆着，绳子另一头拴在柱子上的铁环。可以站起来、可以转身，走不开。衣服按天变旧，**分两级**（castle.md 6.1）：**第 1 级**（一日目夜〜二日目）：衣服皱，石粉掉了一些；**第 2 级**（三日目）：衣服脏、领口松，胡子长约 1.5 cm，脸色暗、眼下发青（颜色图的一层遮罩，按级开，同梅洛斯在路上的做法）。不做伤：他没挨打（ending-cast.md） |

- 押去刑场时（三日目傍晚）双手改成捆在身后，就是结局版的样子。
- 三个样子和结局版用**同一个模型**：围裙、外袍各一个可开关的网格；捆手两种姿势（身前、身后）用动作，绳子是两份网格按姿势显示一份。

## 对话版

- art-direction 9.2 的对话版，面数、贴图照那里。
- 柱廊里坐着说话：坐姿的待机和说话用 UAL 的 `Sitting_Idle_Loop`、`Sitting_Talking_Loop`（同王），双手在身前，说话时手不比划（捆着）。对话镜头蹲下来平视他：玩家站着时镜头会俯视得太多，越肩镜头的高度按他坐着的眼睛高度取〔前端定做法：玩家靠近 `hostage-column` 时自动坐下或蹲下〕。

## 验收

1. 60 px 剪影里，工房的他（宽、围裙）和弟子、フィロストラトス分得开（m3-cast.svg 下方「工房」）。
2. 三日目的第 2 级和第 1 级放在一起，一眼看得出过了两天；但不像受了伤。
3. 「一瞬の疑い」放慢看是一个完整的表情，正常速度下一闪而过，在他身边的人看得到。

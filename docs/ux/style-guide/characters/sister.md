# メロスの妹

> メロスの十六の妹も、きょうは兄の代りに羊群の番をしていた。

梅洛斯的妹妹，十六岁，内向，和哥哥两个人住在村里（`char.sister`）。第三幕（村子）的主角之一，**对话版**（玩家可以和她说话）。声音 D-025：Leda。

共用的规则（尺寸、色表、磨损、轮廓验收）见 [README](../README.md)。图：[m3-cast.svg](m3-cast.svg)。

## 一眼认得出的三样（探索镜头，60 px）

1. **个子小**：1.55 m，村里的大人里最矮（牧童 1.48 m 比她还矮，但他手里有比人高的牧杖）。
2. **浅菘蓝的头巾**：包住头发，在后颈打结，巾尾垂到肩胛骨。村里只有她戴这个颜色。
3. **腰上提起的一圈褶**（kolpos）：放羊时把长衣从腰带里往上提，下摆到小腿中间，腰上鼓出一圈。平日手里拿一根赶羊的细枝条（约 1 m，比牧童的牧杖短得多，没有弯钩）。

婚礼那天换成另一套（下面），三样里只剩个子小；但那天她站在祭坛前，位置就够了。

## 身体和脸

| 项 | 要求 |
|---|---|
| 年龄 | 十六（原作「十六の、内気な妹」） |
| 身高、体型 | 1.55 m，7 头身，瘦小 |
| 姿势 | **内向**：肩稍往里收，头稍低，站着时两手常在身前握在一起。和哥哥说话时会抬头；被问到婚事时低头（「頬をあからめた」：脸红交给表情形变的脸颊一项和叙事，不改皮肤颜色） |
| 皮肤 | `#A87A5C`，晒过，但比梅洛斯浅（她在村里干活，不走远路） |
| 脸 | 圆一点的脸，眼睛大，眉毛细。**不化妆**。表情的主力是眼睛往下看、嘴角轻轻收（害羞），和担心时皱眉（「うるさく兄に質問を浴びせた」） |
| 头发 | 深褐，长，编成一条辫子盘在头巾里，**看不见长发**（art-direction 5.4：头发短或被盖住）。婚礼时面纱下面露一点发际 |

## 婚礼（二日目 12:00 起，到宴席结束）

> 綺麗な衣裳も買って来た。

衣服是梅洛斯从城里买回来的，就是他第一幕背着的那个包袱里的东西（`melos.md`「包袱」）。

| # | 部件 | 材料和颜色 | 做法 | 在 1024 图上约占 |
|---|---|---|---|---|
| ① | 长衣 | **番红花黄 S1 `#AE9150`**，细羊毛 | 到脚踝，不提褶，腰带系在胸下一点（比平日高）。褶子顺着往下垂 | 45% |
| ② | 面纱 | **番红花纱 S2 `#D2BF8E`**，半透明 | 从头顶盖到腰，**说话时掀到脑后，脸和嘴整个露出来**（口型要看得见，art-direction 5.1 第 3 条）。只在仪式那一刻（祭坛前）放下来盖住脸，那时她不说话 | 15% |
| ③ | 头上的花环 | 桃金娘 M1 `#4E5B3B`，白色小花 | 压在面纱上的一圈，和花婿的一样（village.md 6.2「桃金娘的花环」） | 4% |
| ④ | 腰带 | 番红花纱同色的布带 | 胸下系一圈 | 3% |

- **不用红**：緋色只给三样（art-direction 6）。新娘的颜色定成番红花黄，希腊新娘常见的颜色〔推断〕。
- 番红花黄的饱和度比緋 R1 低（README 色表），但面积大、又在真昼的太阳下：前端出了婚礼的画面后，UX 看一眼牧童的緋腰带还是不是画面里最跳的颜色。不是的话把 S1 再压灰，不动緋。
- 婚礼的衣服做成同一个模型的第二套衣服材质和网格（两套共用身体和头），按幕里的时刻换。
- 宴席在屋里（二日目 21:00，beat.13）：同一套，面纱掀在脑后，花环还戴着。雨里进来的：下摆湿。

## 对话版

- 对话版按 art-direction 9.2（档 B 2〜3 万面，52 个表情形变 + 日语元音口型）。
- 头巾、面纱都不能挡住嘴。头巾在下巴以上，面纱掀到脑后时在耳朵后面。
- 害羞的低头不能低到脸出画：对话镜头按她的眼睛高度取景，低头最多约 15°。

## 动起来的部分

- 头巾的巾尾 2 根骨骼，面纱 4 根（掀起、放下是一个动作）。
- 提起来的那圈褶不动，下摆 2 根。
- 枝条是刚体，跟右手。

## 验收

1. 60 px 剪影里，在牧场上和羊、收麦的人、花婿、梅洛斯分得开（m3-cast.svg 下方「村子」那一格）。
2. 婚礼的画面里，新娘的黄和祭坛、桃金娘、院子的土地面分得开；牧童的緋腰带还是画面里最跳的颜色。
3. 对话时面纱和头巾不挡嘴。

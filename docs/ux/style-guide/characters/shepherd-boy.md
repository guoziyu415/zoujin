# 玩家・村の牧童

> メロスの村で、羊を追っている。

玩家的第三个身份（`role.shepherd-boy`，ux-design 5.1）。梅洛斯村里放羊的孩子，人物叫你「坊主」。从第三幕开始：一日目 09:00 在村边的田埂（village.md `field-edge`），能去村子、归途、广场和刑场。

和旅人一样，**玩家看到的是背影**（traveler.md「看得见的只有背影」那几条照用）。

共用的规则见 [README](../README.md)。图：[m3-cast.svg](m3-cast.svg)（第二行是背影）。

## 一眼认得出的三样（探索镜头，60 px，从背后看）

1. **个子小、牧杖比人高**：1.48 m，所有人物里最矮；右手拄的牧杖约 1.6 m，顶上一个弯钩，高过他的头。
2. **羊皮短披肩**：毛朝外，盖住两肩、到背中间，浅色、毛茸茸的边。
3. **深胡桃色短衣上的緋色腰带**：深色的身子、浅色的肩，中间一道红。

**和 art-direction 5.4 原来写的不一样**：原来写「草编的宽檐帽」。改掉：村里收麦的人都戴草帽（village.md 6.1），宽檐又是旅人的标志，牧童戴了在村里就找不到。改成羊皮披肩，不戴帽子。

## 身体

| 项 | 要求 |
|---|---|
| 年龄 | 十二三〔推断：「坊主」〕 |
| 身高、体型 | 1.48 m，6.5 头身（孩子的比例：头大一点，腿短一点），瘦，晒得黑 |
| 姿势 | 站着时把重心压在牧杖上，或者两手搭在杖头上。待机动作是用杖拨一拨地上的东西、看看羊 |
| 皮肤 | `#9A6C4C`，晒黑的，只看得见手、小腿和后颈 |
| 头发 | 深褐，短而乱，不戴帽 |

玩家用自己的声音说话，可能是大人的声音。不因此改身体：人物叫他「坊主」，世界照这个对待他。

## 跟着梅洛斯跑（归途）

- 并肩跑的路段（homeward-road 第 5 节）他在梅洛斯的侧后方，镜头照那一节。孩子跑不过梅洛斯是常识；世界模型里他跟得上，就照跟得上演，步子比梅洛斯快、步幅小。
- 第 2 级以后（过河、山贼）梅洛斯的衣服变破，牧童的不跟着变破：他没游过濁流，也没打架。湿和尘土照常。

## 镜头

- 探索镜头：照 ux-design 6.3 的距离和高度。人矮了，背影在画面里更小；前端看一眼 60 px 的验收（下面第 1 条）还过不过，不过的话按身高把镜头的距离缩一点〔前端定〕。
- 对话镜头：越肩时他的肩膀比对方低。镜头放在他的肩后、取景对着对方的脸（ux-design 6.3 的脸部大小照旧），会有一点仰视，这正是孩子看大人的样子。仰角不超过约 10°，再大就把镜头抬高。

## 动起来的部分

- 腰带尾巴每条 2 根骨骼（同旅人）。披肩的下缘 2 根。
- 牧杖、水袋是刚体。

## 验收

1. 60 px 剪影里，从背后一眼认得出（个子、牧杖、浅色的肩），在村子里和收麦的人、梅洛斯、花婿、妹妹分得开（m3-cast.svg 下方「村子」）。
2. 9:00 第一屏（village.md 第 7 节），他的背影是近景里最暗的一块，緋腰带是画面里饱和度最高的颜色。
3. 对话镜头的仰角不超过约 10°，对方的脸照 ux-design 6.3 的大小。

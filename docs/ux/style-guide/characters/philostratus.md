# フィロストラトス

> 「フィロストラトスでございます。貴方のお友達セリヌンティウス様の弟子でございます。」その若い石工も、メロスの後について走りながら叫んだ。

セリヌンティウス的徒弟，年轻的石匠（`char.philostratus`）。**对话版**。出场：

- 第一幕：工房（石屋の弟子开局时在场；他是弟子的师兄，`role.apprentice` 的 `knownCharacters`）。
- 第二、三幕：城里，工房和刑场附近〔世界模型的计划决定，这里不另写〕。
- 第四幕：三日目 18:30 从城里跑出来，在野の道追上梅洛斯（beat.23，homeward-road 第 7 节）。

声音 D-025：Rasalgethi（和梅洛斯只差约 1 个半音；要不要换 Enceladus 见 ux-design 16.1，D-035 以后真人试听时定）。

共用的规则见 [README](../README.md)。图：[m3-cast.svg](m3-cast.svg)。

## 一眼认得出的三样（探索镜头，60 px）

1. **瘦，往前探着身子**：站着也像要跑。1.70 m，比梅洛斯矮一点、细一圈。
2. **包住头发的本色头巾**：在后颈掖好，没有垂下来的巾尾，头是一个光滑的圆（弟子的头带在脑后垂两条短尾，靠这个分开）。
3. **灰褐短衣上的白石粉**：前襟和下摆一片白。

**画出来以后看到的一件事**：在工房里，弟子（玩家，背影）和他在 60 px 的剪影里只靠头上的巾尾、弟子右胯的木槌分开，偏弱；颜色上弟子有緋腰带和深色皮围裙，分得开。前端做出工房以后在真机上看一眼；还不够就让他在工房里干活时肩上扛一块石料或一根撬棍〔UX 的备选〕。

## 身体和脸

| 项 | 要求 |
|---|---|
| 年龄 | 十八九〔推断：原作「若い石工」〕 |
| 身高、体型 | 1.70 m，7.25 头身。瘦，手长，石匠的手（大、指节粗） |
| 姿势 | **重心靠前**，肩往前，脖子伸出来一点。第四幕跑来时上身前倾得更厉害，喘 |
| 皮肤 | `#9C6E50`，在城里干活，比梅洛斯浅 |
| 脸 | 窄脸，眼睛大、眉毛往上挑（容易慌）。**表情的主力是慌和哭**：原作里他「叫んだ」「おうらみ申します」，然后又劝梅洛斯保命。要做出哭着说话的嘴形（嘴角往下、上唇抖），不做眼泪的特效，眼睛湿交给眼的高光变强 |
| 胡子 | 没有，最多一层很淡的胡茬。嘴看得清 |
| 头发 | 包在头巾里，额前露一点深褐的头发 |

## 服装

| # | 部件 | 材料和颜色 | 做法 | 在 1024 图上约占 |
|---|---|---|---|---|
| ① | 短衣 | **灰褐亚麻 T1 `#85796A`** | 到膝上，两肩盖住，短袖。前襟和下摆有一片白色石粉（和セリヌンティウス同一种白，颜色图里的一层） | 40% |
| ② | 头巾 | 未染的亚麻 L0 | 包住头发，后颈掖进去，不垂 | 10% |
| ③ | 腰带 | 胡桃褐 N1 的布带 | 一圈，侧面打结 | 4% |
| ④ | 凉鞋 | 旧皮革 K1 | 平底 | 8% |

- **没有皮围裙**：工房里只有师父和弟子（玩家）有围裙。他干的是搬运、打下手的活〔推断〕。这样他和弟子在剪影、颜色上都分得开。
- 第四幕跑来时（三日目 18:30）：一路从城里跑来，全身尘土、汗湿（材质参数），头巾歪了一点。

## 对话版

- art-direction 9.2 的对话版。
- 第四幕他是跟着梅洛斯一边跑一边说话的（「メロスの後について走りながら叫んだ」）。野の道上能和他说的两句（homeward-road 第 7 节）照停留点的规矩：玩家说话时他和梅洛斯放慢成快走，镜头照 ux-design 6.3。跑着说话的口型和喘气混在一起：前端把喘气做成一个叠加在口型上的形变〔前端定做法〕。

## 动起来的部分

- 短衣下摆 2 根骨骼。头巾不动。

## 验收

1. 60 px 剪影里，在工房里和弟子、セリヌンティウス分得开（m3-cast.svg 下方「工房」）；在野の道的夕阳逆光里和梅洛斯分得开（梅洛斯这时是结局版，几乎光着上身）。
2. 哭着说话时嘴形读得出，不像在笑。

# 王ディオニス（对话版）

> 「おまえがか？」王は、憫笑した。「仕方の無いやつじゃ。おまえには、わしの孤独がわからぬ。」

M3 里王成为可以对话的人物（`char.king`，声音 D-025：Algieba）：第一幕王座之间审梅洛斯（旅人「連れの者」、随师父的弟子在场），守人质的玩家一日目〜三日目白天也能走进王座之间见他（castle.md 第 0 节）。

**轮廓、颜色、衣服、结局里的样子照 [ending-cast.md](ending-cast.md)「王ディオニス」**，这里只加对话版要的：脸、手、坐姿和王座之间里的样子。共用规则见 [README](../README.md)。

## 脸（对话版的重点）

王的对话镜头是**仰拍**：他坐在 0.9 m 高的台上，玩家在台下（castle.md 第 3 节）。脸在画面上方，灯在他前上方。

| 项 | 要求 |
|---|---|
| 皮肤 | `#B89A86`，蒼白，所有人物里最浅、最冷（ending-cast.md）。不加血色：嘴唇也偏灰 |
| 眉间 | 两道很深的竖纹（「刻み込まれたように深かった」），法线图，**档 B 也要看得清**：仰拍、顶光时这两道纹是他脸上最暗的线 |
| 眼 | 眼窝深，在吊灯下落进阴影；火盆给眼睛一点反光（castle.md 第 3 节），没有这点光读不出他在看谁。眼神冷，不常眨眼 |
| 胡子 | 深灰夹白，短而整齐，**上唇剪开**，嘴看得清 |
| 头发 | 短，向后梳，深灰夹白 |

**表情**（ARKit 的 52 个形变，加日语元音口型，art-direction 9.2）。castle.md 6.1 说王的「憫笑」「北叟笑ん」是脸，用形变做预设、不算动作片段。这里把预设定下来：

| 预设 | 原作 | 怎么做 |
|---|---|---|
| 憫笑 | 「王は、憫笑した」 | 一侧嘴角上提（左），眼睑半垂，眉不动。不露牙。看人像看小孩 |
| 北叟笑む | 「残虐な気持で、そっと北叟笑んだ」 | 嘴角两侧轻轻上提，嘴闭着，眼睛眯一点、眼神往旁边移：笑给自己看，不给对方看 |
| 冷笑・嗤う | 「暴君は、嗄れた声で低く笑った」 | 下巴微抬，嘴角一侧上提，鼻翼一点。声音之外，脸上的动作要小 |
| 孤独 | 「わしの孤独がわからぬ」「わしだって、平和を望んでいるのだが」 | 眉头往中间、往上一点，眼神往下，嘴放松。只在这类句子上出现，**一闪就收回**到平常的冷脸 |
| 平常 | — | 什么都不动的脸。王的默认表情就是没有表情 |

- 结局里「顔をあからめて」：脸红不改皮肤颜色，交给叙事（ending-cast.md）。表情用「孤独」那个预设的轻一档加眼神躲开。

## 手

- 手指长、骨节明显，没干过活。
- 右手食指一枚**印章戒指**（金，小）。不加别的首饰：金只有头带和这枚戒指。
- 坐着时双手搭在王座的扶手上，说话时只抬右手的手腕和手指，不挥手臂（「静かに」）。

## 坐姿和王座之间

- 坐姿的待机和说话用 UAL 现成的 `Sitting_Idle_Loop`、`Sitting_Talking_Loop`（castle.md 6.1，前端 15:57Z）。手势另做，和结局的专属动作一起排。
- 坐下时外袍（深紫 P1）从左肩垂到台阶上，盖住王座的一部分。**深紫在灯火下几乎是黑的**：外袍边上加一道约 3 cm 的织边，暗金褐 `#6E5A3A`（和警吏的旧青铜同色，不用亮金），让灯光照到时看得出布的边和褶。
- 帘子是深靛蓝或深紫（castle.md 第 3 节），王的外袍不能和帘子糊成一片：王比帘子暖一点（P1 偏紫红一点，帘子偏蓝），又有织边和金头带。前端出了王座之间的画面后 UX 看这一点。

## 动起来的部分

- 外袍垂下的一角和下摆 4 根骨骼（坐着时垂在台阶上的那段不动）。
- 头带、戒指是刚体。

## 验收

1. 仰拍的对话镜头里，眉间的两道纹和眼里的反光在档 B 读得出（iPhone，art-direction 9.6）。
2. 「憫笑」「北叟笑む」两个预设放在一起看分得开：前者对着人，后者躲着人。
3. 王座之间的灯火下，王的外袍和帘子分得开。

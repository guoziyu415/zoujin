# 町の老爺

> 老爺は、あたりをはばかる低声で、わずか答えた。「王様は、人を殺します。」

怕王、怕被人听见的老人。旅人在广场上第一个遇见的人（ux-design 5.1），天黑以前想赶回家。结局时站在群众的前排（ux-design 11.1 `in-crowd`）。

## 一眼认得出的三样（探索镜头，60 px）

1. **驼背**，头往前探。
2. **外袍拉起来盖住头**，头顶是一个圆的兜帽形。
3. **拐杖**，比他的肩略高。

三样一起出现的只有他。**刑场的群众里不放「盖头 + 拐杖」的人**（art-direction 5.5 的群众要避开），否则结局时找不到他。

## 身体和脸

| 项 | 要求 |
|---|---|
| 年龄 | 七十岁左右 |
| 身高、体型 | 1.68 m，7 头身；驼背以后头顶约 1.56 m。瘦，手腕和手指骨节突出 |
| 姿势 | 上背弯约 20〜25°，头往前探。右手拄杖，**左手在胸前攥着外袍的边**（怕冷，也是怕的样子）。走得慢，步子小 |
| 皮肤 | 晒了很多年、发灰（`#A07A5F`）。额头、眼角、嘴角的皱纹用法线做（art-direction 9.4），不加面 |
| 脸 | 眼睛总在看周围。眉毛白、稀，眉的动作要读得出来 |
| 胡子 | 白，修短到约 2 cm，**上唇的胡子剪开，不盖住嘴**。口型要看得清（5.1 第 3 条） |
| 头发 | 白，短，基本被兜帽盖住，只露鬓角 |

- 尘土比梅洛斯少，他就住在城里。下摆脏一点，膝盖处的布磨薄。
- 第一幕和结局**不换装**：结局时他在群众前排，玩家要一眼认出（ux-design 11.1）。

## 和场景的关系

- **老爺の家**：广场南边，门朝广场，门前的位置点 `old-man-house`（前端 F-2a 补）。art-direction 4.2 建议的葡萄棚放在他家门口：对话时光从叶子缝里落在他脸上（见 plaza-materials.md）。
- 旅人送他回家（世界模型 `aid.old-man.listen`）是天快黑的时候，门口要有一盏能点的油灯〔推断〕。

## 动起来的部分

- 外袍下摆 2〜4 根骨骼，走得慢，摆动小。
- 兜帽跟着头动，不单独甩。
- 拐杖是刚体，跟右手。

## 验收

1. 60 px 剪影里，从任何方向都认得出（上面三样），和群众分得开。
2. 对话镜头的档 B 上，兜帽下的眼睛和眉读得出来，嘴不被胡子盖住。
3. 17:30 和 19:30（残照）兜帽里的脸不是一片黑；夜里靠门口的灯（art-direction 3.2「夜里，人物附近要有灯火」）。
4. 驼背和小步子的走路动作，和梅洛斯、旅人用不同的动作或者明显的参数差别〔前端定做法〕。

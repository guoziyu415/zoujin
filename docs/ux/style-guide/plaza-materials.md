# 广场材质清单（锡拉库萨广场，含刑场和石屋の工房）

| 项 | 内容 |
|---|---|
| 用途 | 前端 F-2b 换正式材质时照着选、照着调；UX 照着验收 |
| 依据 | art-direction 4.2（材质）、4.3（时代考证）、6（緋色）、7（画面处理）、9.2〜9.5（两档）；前端 F-2a 的 `assets/scenes/syracuse-square/scene.json` 里的材质槽 |
| 状态 | 颜色和粗糙度是 UX 初定的范围，F-2b 的真机画面出来后一起调〔UX 初定〕 |

## 先看这三条

1. **石灰岩是主角。** 地面和王城的墙占第一屏一大半（art-direction 9.3）。锡拉库萨的石灰岩是带蜜色的白，夕阳下发金，但底色本身不能是黄的或橙的：金色要靠光给，不靠贴图。
2. **除緋色以外不用红**（art-direction 6）。布篷、陶瓦、陶器、植物都压低饱和度，日没时画面里饱和度最高的必须是旅人的腰带。
3. **写实的破绽多在时代。** 扫描素材是今天拍的，里面常夹着两千年后的东西。选素材时先过第 4 节。

两条补充：

- **石屋の工房的院子**：地面用同一张石板地，上面加一层石屑和白色的石粉，越靠近长凳越厚〔前端可以用贴花或顶点色〕。院里的石块用 `stone`（细凿面、更亮）：是新切的单块石头，不带层缝，比王城的墙更白、没有晒旧。
- **刑场**：没有专门的材质。磔台用石灰岩细部（5）砌成，磔の柱用粗木（8）。柱脚和台阶被人摸、被人踩得更亮〔推断〕。

## 2. 老爺家门口的葡萄棚

art-direction 4.2 建议放在这里。对话时光从叶子缝里落在他脸上，便宜又好看。

| 项 | 要求 |
|---|---|
| 位置 | 老爺の家门前，盖住位置点 `old-man-house` 和门口，约 3 × 2.5 m |
| 结构 | 4 根去皮的旧木柱，高约 2.4 m，上面搭横杆。藤从一根柱子爬上去，叶子铺满大半个顶 |
| 季节 | 初夏：叶子新长出来，嫩绿；果是青的小串 |
| 光 | 太阳还照得到门口的时候，叶影落在老爺的脸和地上。**不为了叶影另造一个太阳**（art-direction 3「太阳就是时钟」）。门口进了阴影以后，葡萄棚就是一层暗的顶，脸靠天光和门口的灯（old-man.md）。门口什么时候进阴影，前端用实时太阳查一下，写进 F-2b 的说明 |
| 做法 | 叶片用透明贴图的面片。叶影用实时阴影还是投影贴图（cookie），由前端按帧时间定 |
| 门口的灯 | 一盏素烧的油灯，挂在门边或放在墙上的小龛里，天黑以后点着〔推断〕 |

## 3. 共同规则

1. **饱和度**：环境材质的底色均值，HSV 饱和度不超过 0.45（陶瓦和陶器最高），石灰岩和灰泥不超过 0.25。这样人物的衣服（梅洛斯的赭 0.62、旅人的海色 0.37）都比背景跳，緋色（0.80）最跳。
2. **两档同源**（art-direction 9.5）：2048 和 1024 从同一张源图缩出来。前端的 `scene.json` 已经记了每张图两档的平均颜色，验收时每个通道差不超过 2。
3. **不显重复**：探索镜头从约 15 m 外看下去，地面和墙看不出重复的图案。用大尺度的变化打散，例如光照图的 AO、一张整场的脏污遮罩〔前端定做法〕。
4. **一张图代表多大**：按扫描的实际大小来，让石块的大小对（石板每块 60〜120 cm，王城的石块每层 45〜60 cm 高）。现在前端的值是地面 3 m、墙 6 m 一张。对话镜头背后的墙在档 B 上糊的话，墙缩到 4 m 一张〔UX 建议，前端定〕。
5. **脏和磨损跟着人走**：墙脚约 30 cm 变暗；门口、台阶中间、城门到柱子的那条线被踩亮；喷泉周围湿、暗。没人走的角落有尘土和干草。
6. **低角度的光要读得出质感**：17:30 和 18:50 太阳很低，凿痕、石缝和瓦的起伏要在侧光下看得出来。法线的强度在这两个时刻调。
7. **颜色图里不能有光**：选「无光照」的颜色图（albedo）。拍摄时的阳光和硬阴影被烤进颜色图的扫描不用。

## 4. 选扫描素材（CC0）

- **来源**：Poly Haven、ambientCG 这类 CC0 的扫描材质。每张的来源、授权和 sha256 记进 `assets/manifest/`（F-2 卡、S-075），源文件不进仓库。
- **下载**：项目容器访问不了这些网站，要在 zg 的 Mac 上下，并先得到 zg 同意。UX 不下载、不花钱，也不买素材。
- **怎么选**：前端每种材质挑 2〜3 个候选，放进 F-2b 的广场，用同一个镜头在 17:30 和 18:50 各截一张，UX 从里面选。不按网站上的缩略图选：缩略图是中性光下拍的，夕阳下会变。
- **先过 art-direction 4.3 的表**，再专门看这些常混进来的东西：

| 不要 | 常出现在 |
|---|---|
| 水泥灰浆的缝（灰色、直、宽度一样） | 石墙的扫描。希腊的切石墙是干砌的 |
| 机器锯出来的、一样大的方石板；路缘石、沥青、混凝土 | 地面的扫描 |
| 钻孔、铁锈、钢筋、电线、涂鸦、油污 | 墙和地面 |
| 红砖；现代机制瓦 | 墙和屋顶 |
| 仙人掌、龙舌兰的叶子，柑橘的落果，烟头、塑料 | 地面扫描里夹着的杂物 |
| 拍摄时的阳光和硬阴影 | 颜色图（见第 3 节第 7 条） |

## 5. 验收（在 F-2b 里看，先看档 B）

1. **第一屏**（17:30，西南角朝东北，art-direction 第 10 节）：石板地和王城的墙是蜜色的白，有金色但不是橙色。梅洛斯、老爺、旅人站在上面一眼分得开。
2. **日没**（18:50〜19:00）：画面里饱和度最高的是旅人的腰带，陶瓦和布篷都比它淡（art-direction 6）。
3. **探索镜头**：从约 15 m 外看地面和墙，看不出重复。
4. **对话镜头**（1〜3 m）：背后的墙和门在档 B 上不糊成一片，看得出是石头和木头。
5. **升降档**：那一下颜色不变，只是更清楚（9.5）；`scene.json` 里两档的平均颜色每个通道差不超过 2。
6. **时代**：4.3 和第 4 节表里的东西一个都没有。

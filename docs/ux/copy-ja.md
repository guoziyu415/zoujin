# 日语文案表（切片版 v0.1，2026-10-10）

UX 维护。M2 切片（广场、旅人、町の老爺和メロス、第一幕之后跳到三日目の日没）界面上出现的固定日语，按画面排。前端写进代码时以这张表为准；改字先改这张表。

- **出处**：每段标 ux-design 的节号。表里和 ux-design 不一样的地方，以这张表为准，标「改」并写理由，下一次改 ux-design 时同步。
- **状态**：定 = ux-design 或已定的切片稿里有；新 = 这张表第一次写；改 = 改了 ux-design 或原型里的字；核 = 上线前要核实（窗口、iOS 的设置路径）。
- **键名**：`画面.东西`，小写，前端可以照用或换成自己的命名，换了请在这张表里补一列。
- **占位**：`{name}` 人物名（世界模型 `Character.name`）、`{role}` 身份名、`{day}` 日子、`{band}` 时段、`{n}` 数字、`{plan}` 叙事者转述的打算、`{text}` 服务端给的句子。
- **不在这张表里的**：人物和叙事者的话（服务端生成）、幕末去处的标签（数据 `ActExit.label`）、世界模型里的名字和时段词（数据 `clock.labels`）、结局模板句（ux-design 11.4，后端用）、预录台词（ux-design 16.2 和切片稿，后端生成音频）。第 14 节列出切片用到的预录句，方便试听时对照。

## 0. 写法（ux-design 15）

- 界面：丁寧語，短，动词结尾。叙事（地の文）：だ・である体，短句，明朝体。故事外的话（出戏卡、试玩版说明）：界面黑体。
- 不出现：AI（封面告知除外）、イベント、エージェント、刻、ポイント、パラメータ、エラー、クエスト、ミッション、プレイ（说「物語」）。不说「無限」「何万通り」「初の」。
- 数字一律半角：「15分」「1時間半」。不用汉数字（「十分」会读成じゅうぶん）。60 分以上用「時間」。**改**：ux-design 4.2 的倒数写的是「あと二時間ほど」，改成半角，和按钮一致。
- 称呼玩家：旅人是「旅の方」（人物说的，不在界面里）。界面里玩家是「あなた」。
- 人物之间的方向用名字，不用「彼」：「あなた → 老爺」。**改**：ux-design 10.1 写「あなた→彼」，妹是女性，用名字不会错。

**UX 自己顺便看的**（不是编码，有就在「看到的」一栏写一句）：
- 相槌让人觉得自然，还是多余、显得更慢（UQ-1）。
- 人物走过来找你时，玩家理不理（UQ-8）。
- 跳到三日目日没的过场，玩家看不看得懂时间过去了（S-050）。
- 字幕标「書き起こし」或「（字幕を出せませんでした）」时，玩家有没有注意、有没有困惑（很少出现，出现就记）。

## 4. 玩完以后

顺序：玩后问卷（市场调研，§4.2 的那些题）→ **声音那一问** → 回顾录屏 → 短访谈（§6.3）。声音那一问放在问卷之后，不影响 D1 那些题。

**声音那一问**（S-074 ④，口头问，主持人勾）：

> 「広場で、おじいさんとメロスが同じ場面にいたとき、声だけで、いまどちらが話しているか分かりましたか。」

□ すぐ分かった　□ ときどき迷った　□ 分からなかった　□ 同じ場面で二人の声を聞かなかった（不计入）

答「迷った」或「分からなかった」时，追问一句：「どの場面でしたか。」记下录屏时间，回顾时可以回到这一刻。

**怎么判**（PM 已同意，2026-10-10）：有一个人答「分からなかった」，或者两个人以上的录屏里出现老爷↔メロス 的 WHO，就把老爷和梅洛斯这一对写进问题清单，M3 换候选（ux-design 16.1 第 4 条）。只有「ときどき迷った」时，UX 按那一刻的画面和出声设备判断是声音的问题，还是画面上看不出谁在说。

**回顾**：从这三种时刻里选 2〜3 个回看，问「このとき、何を考えていましたか。」
- 关键时刻的演出（立约、日没、结局）；
- 卡住的地方；
- 打开地图或記憶帳的时刻。

暂停卡出现的那一刻不选。

## 5. 收工后

- 主持人当天把填好的表放进研究存放处。
- 市场调研累计暂停卡：总次数 ÷ 实际玩的局数。超过 1/20 就当天告诉 PM（playtest-plan §3.4）。
- UX 和市场调研一起整理问题清单，按「挡路 / 有问题但能玩下去 / 小问题」排，交 PM（playtest-plan §7）。声音那一问单独一行：几个人分不清、什么出声设备、在哪个时刻。

## 6. 切片能玩到尾时要补的

- 切片的实际场景顺序，和按钮、面板的日语原文，补进第 2 节的打点和第 3 节「在哪里」的写法。
- 回顾时优先回看的具体画面。
- 开场要不要请玩家戴耳机：playtest-plan §4.1 说「用自己的手机、戴耳机，尽量像在家里」，R1 照这个，没耳机就外放并记下。

## 两条实际调用路径

- `spikes/backend/zj_spike/s3_runtime.py` 用正式 `gateway.brief.build`、`GeminiLive.open/respond`，发真实文本轮次并接收 Live 音频转写；不持久化音频。没有把评测的 Google 文字 `reply` 替身当成 Live。
- `s3_narrate.py` 用正式 `actions.narrate → Pipeline.call → ClaudeText`，记录模型原文和最终下发文本。超时或长度过滤造成的固定回退单独计数，不算模型通过。
- `s3_action_runtime.py` 另用正式 `eval_api.setup/act`、提取、校验和独立本地数据库事务复测叙事；不手造 `Decision` 或 `Checked`。检查点明确设为 `act.3`，仍不是从开局走到结局的完整流程。

两者都是**固定时刻的条件探针**：按 probe 的 `after` 应用原作节拍效果，在指定地点放置对话人物和旅人。它们没有模拟幕间导航、角色可达性、数据库提交、连续对话或网关输出监控；默认 `act.1` 仅为固定夹具身份上下文。显式的婚礼回归用 `act.3`。四幕真实可达流程和 200 局由 R-1 的另一组评测负责。

最终修复后的 Live 与评分上下文从同一个 `SimState` 导出人物当前人设、知情集合、受限的亲历事实与未发生事件；现有 s092.3 双判法保持不变。模型标记后还需单独进行 agent 阅读，原始判定不覆盖、不删除。这不是人工盲标校准，也不能保证任意话语绝不泄漏。

## 修复

1. 正式 Live 提示补齐已有文字提示中的传闻、他人内心和相对日期规则。`brief.situation_facts` 只给已通过知情与遗忘过滤的事实补上亲历时刻（「今朝、昨日」等）；事实的 `trueFrom` 必须对应实际亲历的节拍。**不传完整 `beat.summary` 或 `variant.summary`**：原作叙述可能提前说雨持续到次日、写出其他人的内心，不能当作当前人物已知。自由改写无既定变体的节拍不补原作摘要。评分的 `lived` 直接使用同一安全事实投影。
2. 叙事提示明确「partial」只指当前动作未完全完成，不能把已经发生的节拍倒退。叙事请求加入已定义的具体动作意图，以及通过校验的候选摘要，排除被拒绝的候选，避免把笼统的 `help` 自行解释成说服、订约。
3. 根任务修复位置投影：遗留的 `var.<人物>.location` 若存在，按权威 `state.locations` 投影，避免同一请求里人物位置矛盾。
4. Live 与文字 reply 同步限制错误前提：玩家的「这场雨」不能代替人物亲眼所见；假设始终按假设回答，不补出桥被冲走之类的原因，也不凭空断言相反事实。已有亲历依据的雨仍允许承认。
5. 新运行器限制有限题目与并发，断点续跑绑定题集、实际提示、模型配置和源码指纹；空转写和失败不算通过。复核保留生成时存下的原提示，校验原回复、提示、状态和世界哈希，不把后续提示版本倒填为生成版本。缺用量时账本使用保守估算，单独标记，不能称全部为实际账单金额。每题记录 `requestId` 以及 Live、双判每次尝试的状态与耗时；超时重试仍保留首笔成本，429 停止，不将成功重试写成两次成功。`--stop-file` 允许完成当前调用后停止派发。

这 497 条生成和旧判定曾使用完整节拍摘要，独立复核发现摘要本身可能含未来雨势时长或他人私心。因此旧统计只是历史结果，**不能作为最终新版本的全量通过证明**；不追补生成源码指纹，也不将新上下文倒填到旧记录。

## 人设信念与知识权限的有限修复

王原有「自认为看透别人」的人设与知识限制存在张力。本次保留全部原始 traits、goals、口吻与台词样本；在 Live / reply 规则以及 Live 人设段之后补一句区分：对别人的看法是自己的信念，不是知道其实际内心的证据；仍可表达泛化的人性悲观、信任或不信任。不把人物统一变成机械回答「不知道」。

第一次隔离候选 `king-final-15` 只在前置规则强化禁止具体未知内心，完成 5/15 后第 3 条明确复发，按停点结束，10 条未开始。第二候选 `king-final-15-v2` 将信念与知识区分放在人设之后，完整完成预先固定的 5 题 × 3 次：原题、措辞改写、王对人性猜疑的正控制、已知下雨起点、未知停雨终点。题目保存在 `spikes/backend/zj_spike/data/r1_king_controls.json`。

第二候选 15/15 完成，45 次调用全部首试成功，现有 s092.3 双判为 **0 flags**。全部逐条阅读，并由独立审核者按 S-092 / S-095 复核前 6 条：**没有确认的 E2，保留 1 条语用争议**——第 1 条针对石工的「难道不会怀疑朋友吗」可理解为王的泛化反问，但也可能让玩家联想到特定怀疑；它没有说时点、次数或已发生，因此不静默升级为确定泄漏。第 2、4、6 条带不确定词的具体情绪猜测未命中未知事实清单，只记措辞观察，不把所有猜测都禁掉。王泛化悲观正控制 3/3 保留；已知雨起点 3/3 承认、未知停雨 3/3 未预知。

本次有限修复接受第二候选，不继续重复原题直到归零；**不等于按独立题数达到正式发布的 1% 上限门槛**，更不抵消旧 60 条的 2 个标记和第一候选失败。评审员校准、完整留出题集和语音听感验收仍未做。

候选在私有源码副本运行，与当时执行的四局评测隔离；验证 12 个实际导入模块、REPO 路径、提示与源码指纹均来自副本，没有改写旧生成指纹。`king-final-15-v2/isolation-verification.json`、`metadata.json`、`agent-review.json` 保留原始证据。用户要求停止真实对局与 CI 后，已确认批次和 worker 退出，解除冻结并将三个候选文件原样同步主树，逐文件哈希与已测副本一致。重录合成 `b0-minimal.jsonl` 的 reply 提示版本；9 项 brief 测试、2 项 replay 测试及 brief Ruff 检查通过。未重启真实模型或全量 CI。先审再出声的后手见同目录 `spoiler-preflight-design.md`，只是设计记录，未实现、未计作完成。

## 叙事回归与夹具边界

`narrate-final` 的 66 条均返回模型文本、没有固定回退。逐条阅读发现其中第 42 条仍出现花婿已经答应却写成尚未点头；进一步检查发现该条是 `partial + 空 checked`，正式 `status_of` 不会产生这种组合。原结果保留为夹具压力测试，不把这组写成全部通过，也不据此向生产请求增加更多剧情摘要。运行器已将无已验候选的通用 `help` 改为 `refused`。

正式数据库回归 `action-runtime` 共 12 次：婚礼准备按钮 3 次实际 `done`；答应后的通用帮助、帮助不在场的王、答应后发送过期准备按钮，各 3 次实际 `refused`。12 次均有真实模型叙事、无固定回退；原文和提交前后状态未出现花婿反悔。未覆盖实际 `partial`，不据此声称覆盖所有动作结果。此前 `narrate-groom-verified` 的 3 次只是手工候选的提示探针，与这 12 次真实事务分别计数。

独立复核保留一条内容观察：第 12 条以「支度はもう調い」解释过期按钮被拒绝，但状态只明确花婿已同意，没有单独记录准备全部完成。这是缺少直接状态依据的拒绝理由补写，不能把 12 条统称为内容全部通过；它未倒退已同意的事实、披露未来关键事件或改变持久状态。本次不据此扩大生产叙事上下文。

## 本机复跑

使用根 workspace 的真实模型依赖（`uv sync --all-packages --extra real`），从已有私密配置加载凭证和模型变量，不将它们写入仓库。需要 `ZJ_VERTEX_PROJECT`、`ZJ_VERTEX_LOCATION`、`ANTHROPIC_API_KEY`、`ZJ_CLAUDE_SONNET`、`ZJ_CLAUDE_HAIKU` 和累计 `ZJ_CLAUDE_LEDGER`。先不加 `--confirm` 看有限估算，再执行；授权的本次任务单项保护 $100，累计保护 $10,000，均不是无限循环。

```bash
PYTHONPATH=spikes/backend uv run --package zoujin-backend --extra real python -m zj_spike.s3_runtime \
  --out "$HOME/.zoujin/out/deferred-20261012/spoiler/new-run" --concurrency 4 --confirm

# 只评阅已有 Live 回复，不再生成；源回复的 state/brief 必须一致。
PYTHONPATH=spikes/backend uv run --package zoujin-backend --extra real python -m zj_spike.s3_runtime \
  --out "$HOME/.zoujin/out/deferred-20261012/spoiler/new-review" \
  --replies-from "$HOME/.zoujin/out/deferred-20261012/spoiler/new-run" --confirm

PYTHONPATH=spikes/backend uv run --package zoujin-backend --extra real python -m zj_spike.s3_narrate \
  --out "$HOME/.zoujin/out/deferred-20261012/spoiler/new-narrate" --confirm
```

本次证据根目录为 `$HOME/.zoujin/out/deferred-20261012/spoiler/`。`runtime-full` 保留最初生成与原始判定；它没有捕获完整的生成端源码指纹，该项明确未知，不能倒填为后续代码哈希。后续复核目录独立记录源码/裁判指纹和原回复文件哈希。`narrate`、`narrate-recheck` 是修复过程证据；最终受限事实投影回归使用 `premise-final-60`；此前 `weather-fixed-84`、`premise-fixed-pilot` 和 `premise-fixed-pilot-v2` 均保留为中间证据。

# R-1 恢复回归检查与真实模型验证

2026-10-12 用户授权恢复四幕剧情、防剧透、CI 和分阶段模拟；本轮真实模型调用及所需费用已明确授权。评审员校准与预录语音试听继续暂缓。项目仍为私有，部署不在本卡范围。

## 工作与验收

1. 恢复已有隔离 CI runner 和六个工作流，修复当前分支的静态检查、单元测试、构建与浏览器检查失败。CI 仍禁用真实模型调用，不挂载本机凭证。
2. 核实四幕用例与当前实际运行路径一致；先运行关键流程，再扩大覆盖。确定性检查、模型评分、跳过、超时和基础设施失败分别报告。
3. 复查防剧透历史错题，核对题集覆盖，验证当前模型路径。未经校准的模型评分只作辅助证据。
4. 先运行约 20–30 局模拟，修复暴露的问题后再运行 200 局，记录结局分布、完成率、超时及实际调用成本。不得用规则推演或假模型结果冒充真实模型模拟。

## 执行边界

- 真实模型在本机运行，使用合成测试输入。原始记录、账本与凭证留在本机私有目录；提交只保存脱敏报告和可复现脚本。
- 授权费用不设业务上限；每轮仍采用有限用例、有限重试和超时，先保存预计调用量，避免故障导致失控循环。
- 不部署、不开放匿名入口；继续保留整站密码保护。
- 完成后由实现以外的角色审核统计口径、失败处理与变更。

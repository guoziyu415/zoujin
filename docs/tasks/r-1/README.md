## 执行边界

- 真实模型在本机运行，使用合成测试输入。原始记录、账本与凭证留在本机私有目录；提交只保存脱敏报告和可复现脚本。
- 授权费用不设业务上限；每轮仍采用有限用例、有限重试和超时，先保存预计调用量，避免故障导致失控循环。
- 不部署、不开放匿名入口；继续保留整站密码保护。
- 完成后由实现以外的角色审核统计口径、失败处理与变更。

## 本轮已确认的修复

- 真实评测的 HTTP 客户端跨步骤复用时，原入口每步新建事件循环，导致 `Event loop is closed`。现在一局使用一个循环，并在成功或异常后关闭。修复后的真实探路局 42 步正常结束，107 次调用全部成功，E7 确定性检查通过。
- 最终幕在没有后续本地节拍的地点等待，会反复拒绝且不推进时间。现在按正式期限结算途中的事件与结局，不强制指定结局类别；两个地点的数据库回归通过。
- 模型请求里旧的位置变量按权威人物位置投影，避免同一人物同时出现在两个地点；不修改存档，不为其他书新增变量。
- 四幕及晚期种子用例显式设置对应幕次。模拟玩家从正式开局进入，可使用实际按钮 ID、确认、公开记忆簿和实际演出台词；每步真实调用，不能默用回放。
- 评估报告单列跳过、缺失、降级与未判分；这些结果不再显示发布门槛通过。200 局保留原定 10 画像及固定分母，半局和失败费用也保留。
- Live 与叙事上下文、防剧透证据边界见 [防剧透记录](spoiler.md)；独立审查见 [评估口径与交叉审查](eval-review.md)。

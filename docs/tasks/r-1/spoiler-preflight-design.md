# 高风险轮次先审再出声：设计记录

状态：未实现、未验证，不计入 R-1 完成项。此次有限修复按现行 S-092 / S-095 没有确认的新 E2，仅留一条语用争议，因此不据此扩建有明显延迟代价的语音管线。本文保留 S-068⑤ / S-086⑦ 的后手：若正式重跑仍不过，在玩家问到未来的轮次先审再出声。事后 `monitor` 无法收回声音，不能抵扣已发生的泄漏。

## 现有代码能复用什么

- `gateway/ws.py::Turn` 已有仅内存的 `pcm_out`、当前转写和取消/作废状态；`_stream` 是音频和人物字幕的统一出口。
- `models/gemini_live.py::_answer` 提供音频、转写、结束和用量事件。正常路径逐片发送，原模型用量应照常记账，即使内容最终不下发。
- `gateway/fallback.py::BufferedTranscriber` 可做玩家音频的独立转写；`fallback_text` 可补人物音频转写。两者已有超时和成本处理，但增加调用会增加延迟和费用。
- `narrator/pipeline.py::Pipeline.call` 已有模型请求、JSON schema、附加校验、超时、有限重试和花费；可复用基础设施，新增正式的分类/复核操作。不能直接把 spike 评审脚本搬进生产依赖。
- `brief.situation_facts` 已按人物知识、遗忘和亲历过滤，可作为允许披露的同源上下文。全知的未知/未来清单只交服务器复核器，不交给角色生成器。

## 不能直接复用的假设

目前 `_answer` 先输出音频，直到 `turnComplete` 和转写收尾后才输出玩家 `input_final`。因此仅在 `_stream` 收到玩家定稿后再判断已经太迟；不能声称现成代码只让高风险语音变慢。`t.flowing` 是暂停消费同一事件流的安全复核闸门，不能清掉后等待流后面的定稿，否则可能互相等待。

普通文字轮次开始时已有玩家原文，可以先分类。语音有两个实在的选择：

1. 松开说话后先独立转写并分类，再决定流式发送还是扣住回复。可以复用转写器，但每个语音轮次都承担转写/分类延迟。
2. 继续读取 Live 所有事件到有界私有缓冲，等玩家最终转写再路由。实现较小，但现在的事件顺序意味着普通语音也可能等完整回答后才出声。

若要真正只增加高风险语音的延迟，需要调整输入转写时序或独立的早期转写路线，并用实际事件顺序和准确率证明安全；不能只靠不稳定的半句转写承诺低风险。此项需要单独评估，不在这轮顺手实现。

## 最小闭环边界

路由只识别所问内容是否涉及未来具体结果、未亲历事件或他人秘密，不判断人物态度是否消极；「你相信人吗」与「石工是否曾怀疑朋友」应分开。判定不确定时进入复核。已知事实的来源应保留 fact ID、人物与此刻状态，支持当前事实的正常回答。

高风险轮次在后台持续 drain 模型事件，音频、人物半句字幕、定稿及 `turn_complete` 均暂不发送。完整文本到齐后按正式知识边界复核；只有允许后，才按原顺序下发**同一份**已审音频/字幕。不能检查一段文字再让 Live 自由生成另一段声音，也不能只扣音频却先泄露字幕。缓冲需有字节数、时长与总超时上限，不落库、不写日志。

复核只拦具体未知事实、未发生结果和时点错置；人物自己的信念、愿望、决心，以及不命中特定秘密的泛化情绪推测仍允许。此次双判对语用歧义的例子表明「再接同一个 judge」本身不构成保证；新生产闸门必须独立做有限的已标输入与故障验证，不能称评审员已校准。

拒绝、缺转写、超时、429 或无效输出都不得放行未审声音；复用现有文字降级能力生成并审核替代文本，或结束为可恢复的无回复。第一版不无限重抽，也不强迫人物照读替代文本。被丢弃的原回复不能进入最近对话、持久话语、记忆或异步叙事输入；需要关闭/重建已记住坏回复的 Live 会话。费用仍保留，重试要绑定原轮次，不能覆盖失败或重复提交。

## 实现前后必须验证的事

- 事件级测试：高风险原音频/字幕在 allow 前零下发；低风险文字仍逐片下发；`turn_complete` 不早发；人物最后转写与审核文本一致。
- 取消、切换人物、作废、断线、安全暂停时私有缓冲销毁；不能在下一轮或重连后补发；审核失败不能进入 `_finish` 的补定稿路径。
- 已知/未知事实对照、一般人性观正控制、未来结果与同义改写负控制、语音定稿晚于音频、缺转写、超时、429、缓冲上限；每种失败完整记费且不重复 Live 生成。
- 实际测量普通/高风险轮次首音与总延迟、分类漏入普通路径的比例、语音/文字质量和调用费用。当前有限 15 条的 Live 耗时不是生产首音基准，不能拿来承诺新路径性能。

先做离线事件与状态不变量，再跑固定、有限的真实对照集；如仍漏，保留原始失败并审视路由和知识依据，不继续对两句原题抽样调优。

## What to do / やること

Complete the full version on top of B-9's slice version; the code stays in `narrator/ending.py`:

B-9 のスライス版の上に完全版を仕上げる。コードは引き続き `narrator/ending.py` に置く：

1. **Weighting for the affected-ranking**: 1 for player events involving the character, 1 for `changedBeats` in which they are a participant, +1 more for mutual aid (player for them, them for the player), 2 for promises with the player (`voided` ones excluded), 1 for each undeleted memory, and +1 for every 10 points trust has moved from its starting value.
   **影響を受けた順位の重み付け**：プレイヤーのイベントでその人物に関わるもの 1、`changedBeats` でその人物が参加者のもの 1、相互の助け（プレイヤーがその人物のために、その人物がプレイヤーのために）でさらに +1、プレイヤーとの約束（`voided` は数えない）2、削除されていない記憶 1 件につき 1、信頼が開始値から 10 離れるごとに 1。
2. **`player.relationships`**: computed by code from undeleted memories (trust, five-step label, `memoryIds`); the model is not allowed to write it.
   **`player.relationships`**：削除されていない記憶からコードで計算する（信頼、5 段階の label、`memoryIds`）。モデルには書かせない。
3. **The request** adds: the full final state, undeleted memories, promises (excluding `voided`), improvised details (excluding those recorded by the source events of deleted memories), and characters' relationships and `forgotYou`. Original utterances are still not given.
   **リクエスト**に加えるもの：最終状態のすべて、削除されていない記憶、約束（`voided` を除く）、即興の設定（削除された記憶の元イベントが記録したものを除く）、登場人物の関係と `forgotYou`。発話の原文は引き続き渡さない。
4. **Generated world endings**: the output adds `variant` (or null). It is stored in `world.variant` (`causedBy` = its citations), while `world.outcome` stays the baseline category; the API's `outcomeId` uses its id, with `baseline: false` (already in api-contract 2.8).
   **生成された世界のエンディング**：出力に `variant`（または null）を加える。`world.variant`（`causedBy` = その引用）に保存し、`world.outcome` は引き続き基本の区分のまま。API の `outcomeId` にはその id を使い、`baseline: false` とする（api-contract 2.8 に既にある）。
5. **Deterministic validation** adds: the `variant` id format (`gen.` + lowercase English and hyphens), its claims are all world model variables equal to their final values, at least 2 events from this playthrough, title ≤ 26 characters; character endings' `claims` agree with the final state; characters whose memories were deleted do not get words like 「覚えて」「記憶」「思い出」; a sentence's citations cannot consist only of the events that made a voided promise.
   **決定的な検証**に加えるもの：`variant` の id の書き方（`gen.` + 小文字の英字とハイフン）、主張がすべて世界モデルの変数で最終値と等しいこと、このプレイのイベントが少なくとも 2 つ、タイトル ≤ 26 字。登場人物のエンディングの `claims` が最終状態と一致する。記憶を削除された登場人物には「覚えて」「記憶」「思い出」のような言葉を書かない。1 文の引用が、取り消された約束を成立させたイベントだけであってはならない。
6. **Model check** (step 4): a new prompt `ending-check` (Sonnet, adaptive / medium, 15 seconds). Once deterministic validation has passed, judge whether the three layers hold together; if not, rewrite with `coherence` and the field names, which counts as one of the two attempts; if both fail, use the template. If the check itself times out, errors, or fails the schema, it does not block, and the Trace records `skipped`. The cost is recorded in `cost_ending_usd`.
   **モデルによる検査**（第 4 ステップ）：新しいプロンプト `ending-check`（Sonnet、adaptive / medium、15 秒）。決定的な検証を通った後で、3 層の筋が通っているかを判定する。通っていなければ `coherence` とフィールド名を付けて書き直し、これを 2 回のうちの 1 回と数える。2 回とも通らなければテンプレートを使う。検査そのものがタイムアウト、エラー、スキーマ不適合になった場合は止めず、Trace に `skipped` と記録する。費用は `cost_ending_usd` に記録する。
7. Template endings also carry `relationships`.
   テンプレートのエンディングにも `relationships` を付ける。

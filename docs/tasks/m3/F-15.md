## 做什么

1. **两个停留点的包**（照川的做法：只进清单、现场生成、两次生成逐字节一致）
   - `road-pass`（峠，第四幕，烘 14:00，+x = 80°）：上山的路、平台、小圣栎、岔口和石堆、之字路和石阶、岩门两块石灰岩、鞍部、羊肠小道（脇道）、南边碎石坡、北边岩壁；山贼藏的岩石背后（`bandit-1〜5`，`auto: false`）；位置点照 UX 2.3。
   - `road-spring`（泉，第四幕，烘 15:45，+x = 100°）：路、干砌石墙、草地、泉的岩坎和岩缝、小水潭、细流和踏石、三棵悬铃木、东边缓坡；位置点照 UX 3.2（含 `player-crouch`）。水潭和细流是清水，`water.kind = "clear"`（页面先按 calm 画，F-19 再分）。
2. **跑的路段**：「跑道」做法。每种路边是一块能首尾相接的路面（长 36 m，两头的地面高度、路的位置一样），页面复制几块往后卷。一个包一种：
   - `road-run-r1`（川 → 峠，湿的坡）、`road-run-r2`（峠 → 泉，石的下坡）、`road-run-r2s`（脇道）、`road-run-r3`（泉 → 野の道，草原）
   - `road-field`（野の道，F1 麦田为循环路面；F2 酒宴、F3 小川、F5 墓和柏树、F6 城门、F1' 麦田小道是 `dyn` 节点，按时钟显示）
   - `road-night`（第二幕夜路：干的路面，加「带泉的路面」「峠顶」两块 `dyn` 布景，不下载泉和峠的包）
   - 跑的路段都用实时太阳，烘的只是天光和遮蔽（UX 8）。
3. **按幕挑包**：`road-pass`、`road-spring`、`road-field` 各写一份 `index.json`（第四幕 → 停留点或野の道，第二幕 → `road-night`）和合起来的 `scene.json`，跑的路段的包不是场景（`partOf` 为空，不进世界模型的核对）。
4. **生成和共用包**：河不动（`build.sh`、`merge_river.mjs` 照旧）；其余 8 个包用 `build_rest.sh`，新贴图在 `rest_tex.py`（不改 `../common/road_tex.py`，免得河和村子的输入变了），`merge_rest.mjs` 用 `../common/roadside.mjs` 的固定键表把共用贴图挪进 `road-common`，字节和河、村子带来的一样；高档贴图跟共用包一致（路、草、露头）。
5. **检查**：`check_rest.mjs`（共用包、draw call、跑段、三处的索引和合起来的布局），`check_committed.sh` 查进仓库的清单；`assets/budgets.json` 的 `scenes` 加新包的预算（停留点进场 ≤ 2.6 MB，跑的路段 ≤ 1.6 MB，draw call 停留点 ≤ 50、路段 ≤ 30）。
6. **页面**：`three/road/runway.ts`（懒加载块里）：载一个跑的包，复制路面往后卷，镜头在两人侧后方平行跟随，时钟从出发走到到达，点一下跳过；野の道按时钟显示 `dyn` 布景。

## 不做

梅洛斯、山贼和フィロストラトス的专属动作（另排）；服装四级（F-16）；跑的路段里说话；`commit` 压住到路段演完的状态管理（F-17 接，本卡只给 `playRun()` 的接口和完成回调）；截图、真机和测评（第 26 步统一做）。

## 验收

每个包 `check_scene.mjs` + `check_rest.mjs` 过；两次草稿生成清单一致；页面单测过、构建过。

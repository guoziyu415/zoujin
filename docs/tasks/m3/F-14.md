## 做

1. **流水线** `assets/pipeline/castle/`：`build.sh [final|draft] [out]` 一条命令出 `assets/scenes/castle-throne/`（包名 = 场景 ID 去掉 `scene.`）。
   - `build_castle.py`：UX 第 2 节的平面，坐标 +x 朝东、旋转 0：城门洞、中庭和四面柱廊（北柱廊两排柱子）、蓄水池井栏、王座之间（22 × 14 m、高 8 m、两排各 4 根柱子、墙脚赭黑、关着的高窗木板窗、三级台阶和 0.9 m 的台、背后的靛蓝厚帘子、青铜吊灯、两个火盆）、塔、远处的丘陵。王座是单独的节点（不进导航，王的点就在王座上）。
   - `castle_tex.py`：广场的贴图（石板、石灰岩、抹灰、瓦、丘陵）加本场景的：打磨的深色石地面、靛蓝羊毛帘子、雕花木头、青铜、墙脚赭黑。没有红（art-direction 6）。强机 2048：地面、抹灰、帘子、王座。
   - 光：**一次烘焙**，约定之夜 20:30：吊灯（6 盏油灯）和火盆（王座之间 2 个、中庭 3 个、城门洞 1 个）是 Blender 里的点光源，天空是无月的星空，没有太阳。灯的位置写在 `layout.json` 的 `lamps` 里，烘焙和页面读同一份。
   - `lamps.mjs`：广场的 `pack_scene.mjs` 只打包「间接光」和遮蔽；这一步再把「完整」的那张（灯的直射 + 反射）打成 `lm/<mesh>_full.ktx2`，写进 `scene.json` 的 `lightmaps.<mesh>.full`，并抄 `lamps`、`hall`。不改广场的脚本（改了会让广场和川的清单 `inputs` 全部过期）。
   - UX 5.2 的「中庭・三日目傍晚」不另烘：照广场的做法，中庭白天用实时太阳 + 烘的遮蔽，墙影是实时的。「中庭・夜」和「王座之间・夜」是同一次烘焙。所以总共一次烘焙，比 UX 估的 3 次少，包更小。
2. **布局** `assets/scenes/castle-throne/layout.json`：UX 第 4 节全部位置点（`king-throne` 第一、`hostage-visit` 第二，其他 `auto: false`），起点 `gate-in`，出口 `{ place.syracuse-square, way.plaza }`，`hall` 是王座之间的屋里范围。
3. **页面**（`apps/web`）：
   - 屋里不吃太阳和天空（UX 3 节、前端 #52 ①）：全局的着色器补丁按片元的世界坐标判断在不在 `hall` 盒子里，盒子里把天空的半球光、环境光（漫反射和反射）去掉，换成烘的灯光（场景的材质）或一层暖的补光（人物）。**实时太阳和它的影子留着**：王座之间的墙、屋顶、关着的高窗都投影，所以下午从大门照进来的那块光、往里走的光带、约 18:05 灭，全是实时太阳自己算出来的（UX 3 节「大门」要的形状），不另做光斑贴图。
   - 中庭的火盆只在夜里亮：烘的灯光在屋外乘一个跟着太阳高度的系数。
   - 跨门槛约 1 秒调曝光（前端 #52 ②，夜里也要）：镜头进了大厅，曝光缓到灯火的曝光；出来缓回去。`lightState.zoneExposure`，`PostFX` 乘上去。
   - 火苗：吊灯和火盆上的发光小片，轻轻摇曳，灯光整体亮度跟着轻轻调（UX 5.2 前端答复）。
   - 王城的这些放在按场景懒加载的块里（`three/castle/`），3D 主包只加着色器补丁和两个字段。
   - 测试页（`DevPanel` 的场景列表）能选王城。
4. **预算**：`assets/budgets.json` 的 `scenes` 加 `castle-throne`（王城不是第一屏；UX 7 节约 5 MB，第一次正式生成 3.16 MB（强机 4.67），加约 10% 定）。
5. **UX v1.1 跟进**（#215 之后）：北柱廊两排柱子对齐回 UX 的柱距，`companion-aside` 挪到 (1.0, −1.8)、`hostage-near` 挪到 (−13.4, 6.6)；高窗、东窗、柱子（r 0.4、高 6.2、柱头和额枋）、三级台阶和台（宽 ±3.4，台单独一块导航，`navRoots` 留住王的点）、单幅帘子和帘杆、王座尺寸和靛蓝坐垫照 v1.1 第 3.1 节；吊灯 8 盏、墙上 4 盏壁灯；门到台阶的中轴浅色石带（`hallaxis`）；屋里镜头拉近（`rig.follow`），屋顶斜面不进导航。
6. **单元测试**：大厅判断和曝光缓动（`castle/hall.test.ts`），后端读场景清单的测试照跑。

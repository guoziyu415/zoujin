## 目标

王、セリヌンティウス、妹、花婿、フィロストラトス、石匠的徒弟（`role.apprentice`）、村里的牧童（`role.shepherd-boy`）七个人，每人和梅洛斯一样出三档：对话版强机 `talk_high`、对话版档 B `talk_std`、走动版 `walk`，加自己骨架上的动作 `anims`（待机、说话、走、跑、冲刺）。脸带 ARKit 52 + 15 个口型形变，和梅洛斯同一套名字，运行时同一套口型驱动。游戏里有包的人用真人替掉灰色假人，没有包的还是假人。

## 做法

一条命令 `assets/pipeline/cast/build.sh [id…]`，全在容器里：

1. **体型**：按钉住的 MPFB 提交（同群众）在容器里用宏参数 + 细节目标建这个人的身体和 game_engine 骨架；把顶点（同一套 hm08 拓扑，按序号）换进梅洛斯的 `Body`，形变保留梅洛斯的增量（ARKit + 口型）。
2. **脸部件**：眉、睫毛、头发跟着皮肤走（每个点按最近几个皮肤点的位移插值）；眼、牙、舌按周围皮肤算一个刚体加缩放的变换，眼球保持圆。骨架的关节换成新身体的。
3. **样子**：每人一份 `cast.json`：宏参数、细节目标、肤色、发色和发型（短卷、短直、往后梳、长发挽起）、胡子（上唇剪开，口型看得见）、服装件（chiton / exomis 露哪边肩 / himation / 面纱 / 头带 / 花环 / 皮鞋或凉鞋）和颜色（UX 色表）。服装从 MPFB 的辅助网格（tights、skirt）往外挤出、按平面裁边，重新展 UV，贴图在容器里按固定种子生成（平纹、尘土、褪色），两次生成一致。
4. **导出**：梅洛斯同一套 `lod_export.py`（三档、合材质、按 UAL 重定向动作）和 `compress.mjs`（KTX2 + meshopt）。产物在 `assets/cast/build/<id>/`，不进仓库；进仓库的只有清单 `assets/cast/cast.json`（每档大小、面数、sha256），`check_cast.mjs` 按 `budgets.json` 的人物预算查。
5. **运行时** `three/cast/`：按人物 ID 找包（`/cast/<id>/walk.glb`、对话时 `talk_std.glb`/`talk_high.glb`），`People.tsx` 有包就用，带待机 / 走 / 跑的动画混合；没有包就是灰色假人。说话时按音量开合嘴（`jawOpen` + `viseme_aa`），眨眼。

## 不做

不改 `packages/contracts`。不做布料模拟。不跑截图、真机、测评（D-038，第 26 步统一做）。不买素材：只用 MPFB 的 CC0 数据、梅洛斯文件里打包的 MPFB 系统素材（CC0）、Quaternius UAL（CC0，不进仓库）。

## 验收

- `build.sh` 一条命令出七个人；`check_cast.mjs` 查过预算（talk_high ≤ 6.5 MB / 4 万面，talk_std ≤ 4 MB，walk ≤ 0.5 MB / 8k 面，骨骼 ≤ 60）。
- 运行时单元测试：人物 ID 到包的对应、没有包退回假人、口型驱动。
- UX 看样子、iPhone 帧时间：第 26 步统一。

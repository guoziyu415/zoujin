## Goal / 目標

Seven characters — the king, Selinuntius, the sister, the groom, Philostratus, the stonemason's apprentice (`role.apprentice`) and the village shepherd boy (`role.shepherd-boy`) — each get three tiers like Melos: dialogue version high-end `talk_high`, dialogue version tier B `talk_std`, walking version `walk`, plus motions on their own rig, `anims` (idle, talk, walk, run, sprint). Faces carry ARKit 52 + 15 mouth-shape morphs, with the same names as Melos and driven at runtime by the same lip-sync driver. In the game, characters with a pack replace the gray mannequin with a real person; those without a pack stay mannequins.

王、セリヌンティウス、妹、花婿、フィロストラトス、石工の弟子（`role.apprentice`）、村の牧童（`role.shepherd-boy`）の 7 人。それぞれメロスと同じく 3 ティアを出す：会話版ハイエンド `talk_high`、会話版ティア B `talk_std`、歩行版 `walk`。さらに自分のリグの上の動作 `anims`（待機、話す、歩く、走る、全力疾走）。顔は ARKit 52 + 口形 15 のモーフを持ち、名前はメロスと同じで、実行時は同じ口パクの駆動を使う。ゲームの中では、パックのある人物は灰色のマネキンを本物の人に置き換え、パックのない人物はマネキンのまま。

## Approach / やり方

One command, `assets/pipeline/cast/build.sh [id…]`, all in the container:

1 つのコマンド `assets/pipeline/cast/build.sh [id…]` で、すべてコンテナの中で行う：

1. **Body shape**: from the pinned MPFB commit (as for the crowd), build this character's body and game_engine rig in the container with macro parameters + detail targets; swap the vertices (same hm08 topology, by index) into Melos's `Body`, keeping Melos's morph deltas (ARKit + mouth shapes).
   **体型**：固定した MPFB のコミット（群衆と同じ）から、コンテナでマクロパラメータ + ディテールターゲットを使ってこの人物の体と game_engine のリグを作る。頂点（同じ hm08 トポロジー、番号順）をメロスの `Body` に入れ替え、モーフはメロスの差分（ARKit + 口形）を残す。
2. **Face parts**: brows, lashes and hair follow the skin (each vertex interpolated from the displacement of its nearest few skin vertices); eyes, teeth and tongue get a rigid transform plus scale computed from the surrounding skin, keeping the eyeballs round. The rig's joints are swapped for the new body's.
   **顔のパーツ**：眉、まつ毛、髪は肌について動く（各点を近くのいくつかの肌の点の変位で補間する）。目、歯、舌は周りの肌から剛体 + スケールの変換を 1 つ計算し、眼球は丸いままに保つ。リグの関節は新しい体のものに置き換える。
3. **Appearance**: one `cast.json` per character: macro parameters, detail targets, skin color, hair color and style (short curls, short straight, combed back, long hair pinned up), beard (cut open at the upper lip so the mouth shapes are visible), clothing pieces (chiton / exomis and which shoulder it bares / himation / veil / headband / garland / leather shoes or sandals) and colors (UX color table). Clothing is extruded outward from MPFB's helper meshes (tights, skirt), trimmed by planes and re-UV-unwrapped; textures are generated in the container from a fixed seed (plain weave, dust, fading), and two generations are identical.
   **見た目**：人物ごとに `cast.json` を 1 つ：マクロパラメータ、ディテールターゲット、肌の色、髪の色と髪型（短い巻き毛、短い直毛、後ろになでつけ、長い髪をまとめ上げ）、ひげ（上唇のところで切り開き、口の形が見えるようにする）、衣服のパーツ（キトン / エクソミスとどちらの肩を出すか / ヒマティオン / ベール / 鉢巻き / 花輪 / 革靴またはサンダル）と色（UX の色表）。衣服は MPFB の補助メッシュ（tights、skirt）から外側に押し出し、平面で裁ち落とし、UV を展開し直す。テクスチャはコンテナで固定のシードから生成し（平織り、ほこり、色あせ）、2 回の生成が一致する。
4. **Export**: the same `lod_export.py` as Melos (three tiers, merged materials, motions retargeted per UAL) and `compress.mjs` (KTX2 + meshopt). Outputs live in `assets/cast/build/<id>/`, not in the repo; only the manifest `assets/cast/cast.json` (size, face count and sha256 per tier) goes into the repo, and `check_cast.mjs` checks it against the character budget in `budgets.json`.
   **エクスポート**：メロスと同じ `lod_export.py`（3 ティア、マテリアルの統合、UAL に従った動作のリターゲット）と `compress.mjs`（KTX2 + meshopt）。生成物は `assets/cast/build/<id>/` に置き、リポジトリには入れない。リポジトリに入れるのは一覧 `assets/cast/cast.json`（ティアごとのサイズ、面数、sha256）だけで、`check_cast.mjs` が `budgets.json` の登場人物の予算で確認する。
5. **Runtime** `three/cast/`: find the pack by character ID (`/cast/<id>/walk.glb`, and `talk_std.glb`/`talk_high.glb` during conversation); `People.tsx` uses a pack when there is one, with animation blending for idle / walk / run; without a pack it is the gray mannequin. While speaking, the mouth opens and closes by volume (`jawOpen` + `viseme_aa`), and the eyes blink.
   **実行時** `three/cast/`：人物 ID でパックを探す（`/cast/<id>/walk.glb`、会話中は `talk_std.glb`/`talk_high.glb`）。`People.tsx` はパックがあればそれを使い、待機 / 歩く / 走るのアニメーションをブレンドする。パックがなければ灰色のマネキン。話している間は音量で口を開閉し（`jawOpen` + `viseme_aa`）、瞬きをする。

## Out of scope / やらないこと

`packages/contracts` does not change. No cloth simulation. No screenshots, real devices or evals (D-038; done together at step 26). No buying assets: use only MPFB's CC0 data, the MPFB system assets packed in Melos's file (CC0), and Quaternius UAL (CC0, not in the repo).

`packages/contracts` は変えない。布のシミュレーションはしない。スクリーンショット、実機、評価は行わない（D-038、第 26 ステップでまとめて行う）。素材は買わない：MPFB の CC0 データ、メロスのファイルにパックされた MPFB のシステム素材（CC0）、Quaternius UAL（CC0、リポジトリには入れない）だけを使う。

## Acceptance check / 受け入れ確認

- `build.sh` produces the seven characters with one command; `check_cast.mjs` passes the budget (talk_high ≤ 6.5 MB / 40k faces, talk_std ≤ 4 MB, walk ≤ 0.5 MB / 8k faces, bones ≤ 60).
  `build.sh` の 1 つのコマンドで 7 人を出す。`check_cast.mjs` で予算を確認済み（talk_high ≤ 6.5 MB / 4 万面、talk_std ≤ 4 MB、walk ≤ 0.5 MB / 8k 面、ボーン ≤ 60）。
- Runtime unit tests: mapping from character ID to pack, falling back to the mannequin without a pack, the lip-sync driver.
  実行時の単体テスト：人物 ID からパックへの対応、パックがなければマネキンに戻る、口パクの駆動。
- UX looking at appearance, and iPhone frame time: done together at step 26.
  UX による見た目の確認と iPhone のフレーム時間：第 26 ステップでまとめて行う。

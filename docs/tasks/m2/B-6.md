**2. Generation script** (`zoujin-voice`, `services/backend/src/zoujin_backend/voice/`)

**2. 生成スクリプト**（`zoujin-voice`、`services/backend/src/zoujin_backend/voice/`）

- Following the `casting` approach:
  `casting` のやり方に従う：
  - open one Live session per voice, with system instructions "this character; read the original text exactly once" plus the 「人物：…」 assembled above (plus 「場面：…」 when there is a scene); lines in different scenes are not in the same session (a session has only one set of system instructions);
    声ごとに Live セッションを 1 本開き、システム指示は「この人物として、原文をそのまま 1 回だけ読む」に上で組み立てた「人物：…」を加えたもの（場面があれば「場面：…」も加える）。場面の違うセリフは同じセッションに入れない（1 本のセッションにシステム指示は 1 つだけ）；
  - each line is sent as one text turn, receiving PCM16, 24 kHz, mono.
    各セリフを文字の 1 ターンとして送り、PCM16、24 kHz、モノラルで受け取る。
  - Each line is read 3 times (3 sessions, not three times in a row in the same session, so it doesn't learn from the previous take); aizuchi are read 6 times (short, with a low pass rate; adjusted after UX's measurements).
    各セリフは 3 回読む（セッション 3 本。前の回をまねないよう、同じセッションで 3 回続けては読まない）。相槌は 6 回読む（短く、通る率が低いため。UX の計測後に変更）。
- Automatic checks (backend-design 3.6): of the takes that pass, keep the one whose length is closest to the median:
  自動チェック（backend-design 3.6）：通った回のうち、長さが中央値にいちばん近いものを残す：
  1. Length: discard takes more than twice as long or less than half as long as the median of the takes; also compare against the number of kana morae (0.08–0.25 seconds per mora; discard anything outside that).
     長さ：各回の中央値の 2 倍より長いもの、半分より短いものは捨てる。さらに仮名の拍数とも比べる（1 拍 0.08〜0.25 秒。外れたものは捨てる）。
  2. Truncation: discard takes that still have sound in the last 0.1 seconds (not ending in silence).
     途切れ：最後の 0.1 秒にまだ音がある（無音で終わっていない）ものは捨てる。
  3. Misreading, reading twice: compare against the original text using fallback transcription (S-071 ③, a text model listening to the audio); discard takes with a character error rate over 20%; discard takes whose transcript contains the original twice.
     読み間違い、二度読み：フォールバック文字起こし（S-071 ③、テキストモデルが音声を聴く）で原文と比べ、文字単位の誤り率が 20% を超えるものは捨てる。文字起こしに原文が 2 回出てくるものは捨てる。
  4. Aizuchi (changed after UX measurement 20261011-121014; previously over 0.5 seconds was only flagged, not discarded): discard takes whose voiced span exceeds 0.5 seconds (UX's method: 40 ms windows, within 30 dB of the loudest), whose trimmed file exceeds 0.6 seconds, or with pitched windows under 40% (whisper, breathy voice); if none pass, run again without relaxing.
     相槌（UX の計測 20261011-121014 の後に変更。以前は 0.5 秒超えは印を付けるだけで捨てなかった）：有声の範囲が 0.5 秒を超える（UX の測り方：40 ms の窓で、最大音量から 30 dB 以内）、切り詰めたファイルが 0.6 秒を超える、音高のある窓が 4 割未満（ささやき、息声）のものはすべて捨てる。どれも通らなければもう一度実行し、基準は緩めない。
  5. A character's "couldn't catch that" and "wait a moment" are compared with the same character's free conversation: takes within ±2 semitones of median pitch and ±25% speaking rate are preferred; if none are within range, pick the closest one, flag it in the audit sheet for zg to listen to, and don't rerun.
     人物の「聞き取れない」「ちょっと待って」は同じ人物の自由会話と比べる：音高の中央値 ±2 半音、話す速さ ±25% 以内のものを優先する。どれも範囲内になければいちばん近いものを選び、審査シートに印を付けて zg に聴いてもらい、再実行はしない。

  For a line where none pass, the audit sheet states the reason and it goes to UX; it is not put in the voice list.

  どれも通らなかったセリフは、審査シートに理由を書いて UX に渡し、音声リストには入れない。
- Processing:
  処理：
  - trim leading and trailing silence to 80 ms each; aizuchi 20 ms at the head and 80 ms at the tail (50 each for hard onsets; check truncation before trimming); pad with silence where the raw take has too little at either end;

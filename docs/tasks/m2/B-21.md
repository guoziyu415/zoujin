## What was done / やったこと

- New prompt `suggest` (`models/prompt_texts/suggest.txt`, Haiku, thinking off, 3 seconds): input is the persona, the situation, the player's identity, the two lines of this turn (if any), and the labels of the actions possible right now; output is 2–3 `{text, kind}` (`ask` / `act` / `accept` / `decline`). Rules follow UX 7.8: concrete, able to lead to something happening, not all questions, when a character asks for help one accepts and one says 「いまは、いい」, and never mention what the player doesn't know.
  新しいプロンプト `suggest`（`models/prompt_texts/suggest.txt`、Haiku、思考オフ、3 秒）：入力は人物設定、状況、プレイヤーの身分、このターンの 2 つのセリフ（あれば）、今できるアクションの label。出力は `{text, kind}`（`ask` / `act` / `accept` / `decline`）を 2〜3 個。ルールは UX 7.8 に従う：具体的で、何かが起きることにつながり、全部が質問にならない。人物が助けを求めたら 1 つは引き受け、1 つは「いまは、いい」。プレイヤーが知らないことは言わない。
- `Pipeline.suggest()`: if all of them are questions, treat it as a failure and retry once; if both attempts fail, show nothing (no suggestions this time).
  `Pipeline.suggest()`：全部が質問なら不合格として 1 回だけ再送し、2 回ともだめなら出さない（今回は候補なし）。
- Gateway `Conn.suggest_later()`:
  ゲートウェイ `Conn.suggest_later()`：
  - after the character finishes a turn (voice, text, speak-first on landing) and it has been handed to the narrator, generate in the background and push `suggestions { turnId, character, items }`;
    人物が 1 ターン話し終え（音声、文字、到着時に人物から話しかける場合）、ナレーターに渡した後、バックグラウンドで生成して `suggestions { turnId, character, items }` を送る；
  - push once when a session has just become ready (switching characters, a warm-up hit, resuming), without `turnId`;
    セッションの準備ができた直後（人物の切り替え、ウォームアップの的中、再開での引き継ぎ）に 1 回送る。`turnId` は付けない；
  - if during generation the player starts another turn, switches characters, enters the ending, or the out-of-story card is open: don't push (it is stale);
    生成中にプレイヤーが次のターンを始めた、人物を替えた、エンディングに入った、物語の外に出るカードが開いている：送らない（古くなっている）；
  - no automatic pushes in the economy tier or when degraded (backend-design 5.3, `budget.policy().candidates_on_demand`).
    節約モードと縮退時は自動で送らない（backend-design 5.3、`budget.policy().candidates_on_demand`）。
- Cost goes into the new column `playthrough_metrics.cost_suggest_usd` (migration 0010) and counts toward the per-game budget (B-14 sums all `cost_*_usd`). The suggestions themselves are not persisted.
  費用は新しい列 `playthrough_metrics.cost_suggest_usd`（マイグレーション 0010）に入れ、1 プレイあたりの予算に含める（B-14 はすべての `cost_*_usd` を合計する）。候補そのものは DB に保存しない。

## Out of scope / やらないこと

- Generating only when 「？」 is tapped in the economy tier: the contract has no message yet for the frontend to request suggestions; adding one is a contract change (frontend + backend), to be proposed separately. For now the economy tier simply doesn't push.
  節約モードで「？」をタップしたときだけ生成すること：契約にはまだフロントエンドが候補を要求するメッセージがなく、加えるなら契約の変更（フロントエンド + バックエンド）になるので、別に提案する。今のところ節約モードでは送らないだけ。
- "Hide after the player has spoken on their own 3 times" is a frontend rule (ux-design 7.8); the server keeps pushing.
  「プレイヤーが自分で 3 回話したら畳む」はフロントエンドのルール（ux-design 7.8）で、サーバーはそのまま送り続ける。

## Tests / テスト

`tests/test_gateway_b21.py`: the prompt's output and the retry when all are questions; one push each after a session becomes ready and after a turn; no push in the economy tier. In `test_gateway.py`, the helper that orders messages by turn skips `suggestions` (their arrival time is not fixed).

`tests/test_gateway_b21.py`：プロンプトの出力と、全部が質問だったときの再送。セッションの準備完了後とターンの後にそれぞれ 1 回送る。節約モードでは送らない。`test_gateway.py` の、ターンごとにメッセージの順序を並べる補助関数は `suggestions` を飛ばす（届く時刻が決まっていないため）。

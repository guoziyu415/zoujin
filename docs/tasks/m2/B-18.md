## Goal / 目標

The five characters 王, セリヌンティウス, 妹, 花婿 and フィロストラトス can talk just like メロス and 老爺: Live uses each one's own voice and character settings, and the narrator judges the turn as usual (the same for text turns and for text replies after degradation).

王、セリヌンティウス、妹、花婿、フィロストラトスの 5 人が、メロスや老爺と同じように話せる：Live はそれぞれの声と人物設定を使い、ナレーターは通常どおりそのターンを判定する（文字のターンや、縮退後の文字の返答も同じ）。

## Current state, as found / 調べた現状

- The narrator (extraction, checks, `reply`), the Live system instructions (`gateway/brief.py`), output-side monitoring and memory all follow the characters in the world model; no character is hard-coded. In the draft world model all five are `talkable`, and all have voices in `voices_of()`.
  ナレーター（抽出、チェック、`reply`）、Live のシステム指示（`gateway/brief.py`）、出力側の監視、記憶は、すべて世界モデルの人物に従って動き、人物をハードコードしていない。草稿の世界モデルでは 5 人とも `talkable` で、`voices_of()` にも全員の声がある。
- What is missing: the fake Live has no lines for them (they all use the `default` 「……ああ。」), and no test proves these five work end to end.
  足りないもの：偽 Live に彼らのセリフがない（全員 `default` の「……ああ。」を使う）。この 5 人が最後まで通ることを示すテストもない。

  `fixtures/fake-voice/lines.json`：5 人それぞれにセリフ 1 つと、先に話しかける一言を 1 つ（偽 Live とモック用で、台本ではない）。
- `tests/test_gateway_b18.py`:

## Along the way / ついでに

- After B-14 was merged, each turn's voice seconds and today's usage were written to the database synchronously at the end of the turn, which slowed the wrap-up and turned B-4's retraction timing test red. Changed to a background write (`Voices._voice_seconds`); cost is still written synchronously (needed for the budget check before the next turn starts).
  B-14 がマージされた後、ターンごとの音声秒数と今日の使用量をターンの締めで同期的に DB に書いていたため、締めが遅くなり、B-4 の取り消しのタイミングのテストが赤になった。バックグラウンドで書くように変えた（`Voices._voice_seconds`）。費用はこれまでどおり同期で書く（次のターンの開始前に予算を判定するのに使う）。

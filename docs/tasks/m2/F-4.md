# F-4 刑场的群众：实例化的低模人群

| 项 | 内容 |
|---|---|
| 阶段 | M2（切片） |
| 写卡 | 前端（2026-10-10；PM 定编号 F-4，排在 F-2b 之后） |

## 目标

三日目日没的刑场站着 12〜20 个群众（PM 定的 R1 数量），背对城门、面向柱子，各自轻轻晃，动作错开不整齐；梅洛斯爬上磔台时一阵「どよめき」从台边往外传；王改心后欢呼。警吏、刑吏、緋のマントの少女用同一套做法。整群加起来只多几次 draw call，档 B 上帧时间不超预算。

## 依据

- `docs/ux/art-direction.md` v1.3：5.5（群众：实例化低模，3〜4 种体型 × 3 种服装 × 颜色微调，时间错开，逆光剪影）、6（緋色只给三样）
- UX `docs/ux/style-guide/characters/ending-cast.md`（群众、警吏、少女的服装和「不放」的清单）、项目文件夹 `ux/slice/ending-shots.md`（镜头 1、3、5、7、8、10）

- 前端 `estimates/slice-art-volume.md`

## 范围

**做**

1. **群众低模**：MPFB 在 zg 的 Mac 上出 3〜4 种体型 × 3 种服装（男长衣加外袍、女盖头、干活的男人戴圆毡帽），之后全在容器里：减到约 3k 面一个〔估算，A-0 走动版 8k 的下一级〕，所有体型共用一张 1024 的衣服图和一张皮肤图，衣服颜色在色表（L0、W0、N1、B1、G1、A1）里按实例换。骨架和 A-0 相同，去掉手指第三节。
2. **动作烤进贴图**：同一套骨架，所以把每段动作每一帧的骨骼矩阵烤进一张贴图，所有体型共用（约 50 根骨骼 × 60 帧，每段约 150 KB〔估算〕）。比按顶点烤小一个数量级。R1 三段：站着晃、どよめき、欢呼；UX 的变体「回头让路」排在第四段，可以减（UX 的减法顺序第 ①）。流水线脚本放 `assets/pipeline/crowd/`，和广场一样只进清单、现场生成、两次生成逐字节一致。
3. **运行时 `three/crowd/`**：每种体型和服装一个 `InstancedMesh`，顶点着色器按实例读动作贴图做蒙皮；每个实例有自己的动作、时间偏移、颜色和朝向。站位在 `layout.json` 里加一个刑场群众区（多边形加朝向点），实例在区里按最小间距撒点，种子固定。
4. **演出用的接口**（给以后的结局演出卡调）：`wave(from, speed)` 让どよめき从一点往外传；`cheer()`；`part(path)` 让路径两边的人回头、往两边让。只做这三个，不做群众寻路。
5. **变体**：警吏（锥形盔、矛，刚体挂在头和手上，也实例化）、刑吏（不戴盔、卷袖）、少女（小个子、头纱、怀里一团布）。少女递斗篷那一下由结局演出换成单独的人物，不在本卡。
6. **CI**：群众包的下载大小进 `assets/budgets.json`；无头 Chromium 里放 20 个实例，数 draw call。

**不做**

- 结局的镜头和演出编排（另一张卡）；群众的声音；和群众对话；第一、二天广场上的行人。

## 接口

不改 `packages/contracts`。读 `scene.json` 的群众区；谁在刑场、什么时候出场按世界模型的 `char.crowd`、`char.maiden` 和节拍（数据在改它们的开局地点），由结局演出卡接到本卡的接口上。

## 验收

- 生成脚本一条命令跑通；两次生成的清单逐字节一致；大小在预算内。
- 广场 18:50，20 个群众：多出的 draw call ≤ 8（不算阴影）；Playwright 截图从群众背后看柱子，剪影高低错落、没有两个人同步晃；控制台无错误。
- 计测页上 L1 多出的一帧 GPU 时间有数字，写进 PR〔目标 ≤ 1.5 ms，待测〕。iPhone 上补测，不挡 PR，经 PM 安排。
- UX 看：60 px 剪影里群众和梅洛斯、老爺、旅人、警吏、王分得开；群众里没有「不放」清单里的东西。

## 分几个 PR

1. 资产：群众低模、动作贴图、清单、CI 预算。
2. 运行时：`three/crowd/`、三个接口、测试页和截图。

## 禁止

不部署，不碰密钥，不调模型，不花钱，不买素材。素材只用 CC0（MPFB 的系统素材、Quaternius 的动作）；不用 CMU 动作捕捉（不是 CC0）。在 zg 的 Mac 上装东西或下载，先在前端线程给 zg 看清单和命令。

## 评审

两个代码 PR 都是数据和 PM（D-024 的两份评审）：数据看出场时机和节拍对不对得上；PM 核对 UX 对画面和剪影的意见（UX 看截图，意见经 PM 记录）。

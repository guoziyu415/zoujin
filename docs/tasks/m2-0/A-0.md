## Goal / 目標

Take one character (Melos) through the whole realistic-character pipeline and answer one question: **using only free assets and scripts, can we make a character that passes UX checkpoint 3 (face to face, does he look like a real person), and how much download size, frame time and labor does it cost?**

1 人の登場人物（メロス）でリアルな人物のパイプラインを最初から最後まで通し、1 つの問いに答える：**無料の素材とスクリプトだけで、UX のチェックポイント 3（向かい合ったときに本物の人間に見えるか）を通る人物を作れるか。そのためにダウンロード量、フレーム時間、人手がどれだけかかるか。**

When it is done: zg opens a private test page on the iPhone and stands face to face with Melos in the plaza at three times of day — 17:30, true noon 真昼, and 18:50 backlight. He blinks, looks at you, moves his mouth along with three Japanese lines, and idles in dialogue; in the exploration camera you watch him run; and tier B and high-end can be switched and compared within the same shot.

完成すると次のものが見られる：zg が iPhone で非公開のテストページを開き、広場の 17:30、真昼、18:50 の逆光という 3 つの時刻でメロスと向かい合う。メロスは瞬きをし、こちらを見て、日本語の 3 つのセリフに合わせて口を動かし、会話の待機をする。探索カメラでは彼が走るのを見る。同じショットの中でティア B とハイエンドを切り替えて比べられる。

**What the container cannot do, and why** (checked 2026-10-10): Blender 5.2 works in the container, but the network only reaches npm and PyPI and cannot reach GitHub, the Blender extensions site, the MakeHuman asset site, Quaternius or Poly Haven, so MPFB, its system assets and the motion capture cannot be downloaded. npm has an old 2016 copy of MakeHuman data, with no facial expression morphs and AGPL in its file headers; it can only serve as a stand-in to measure size and frame time, not as the real Melos. So steps 1 and 3 and the asset downloads must be done on zg's Mac (Blender 5.2.1 is installed). The approach is PM's option (b): open Remote Control in the frontend thread and start a Claude Code session on zg's Mac, which handles installing, downloading and opening Blender; the modeling and shape tuning are done by the frontend thread operating the Blender MCP on the Mac through the device connection and looking at screenshots. Conditions: work only in a newly created `~/Developer/zoujin-art/`, do not touch `~/Developer/zoujin-spike`, gcloud or credentials; before installing the MPFB extension, downloading CC0 assets or running any command that changes the Mac, first show zg the list and the commands in the frontend thread; only models, textures and scripts are pulled back into the container.

**コンテナでできない部分とその理由**（2026-10-10 に確認）：コンテナ内では Blender 5.2 が使えるが、ネットワークは npm と PyPI にしか通じず、GitHub、Blender の拡張機能サイト、MakeHuman の素材サイト、Quaternius、Poly Haven にはアクセスできない。そのため MPFB、そのシステム素材、モーションキャプチャはいずれもダウンロードできない。npm には 2016 年の古い MakeHuman データがあるが、顔の表情モーフがなく、ファイルヘッダーには AGPL と書かれている。サイズとフレーム時間を測る代役にしか使えず、正式なメロスにはできない。したがって第 1、3 ステップと素材のダウンロードは zg の Mac で行う（Blender 5.2.1 はインストール済み）。やり方は PM が決めた (b)：フロントエンドのスレッドで Remote Control を開き、zg の Mac で Claude Code のセッションを起動して、インストール、ダウンロード、Blender の起動を担当させる。モデリングと形の調整は、フロントエンドのスレッドがデバイス接続を通じて Mac 上の Blender MCP を操作し、スクリーンショットを見ながら行う。条件：新しく作る `~/Developer/zoujin-art/` の中だけで作業し、`~/Developer/zoujin-spike`、gcloud、認証情報には触れない。MPFB 拡張のインストール、CC0 素材のダウンロード、その他 Mac を変更するコマンドは、事前にフロントエンドのスレッドで一覧とコマンドを zg に見せる。コンテナに持ち帰るのはモデル、テクスチャ、スクリプトだけ。

## 目标

`apps/web` 在本地对着 B-1 的 mock 服务走完一轮文字对话：邀请码登录 → 封面 → 选身份 → 世界屏幕（3D 先放占位）→ 打字说一句 → 看到人物字幕、一个事件的轻反馈和时钟前进 → 断网再连上，补发的消息不重复、不丢。CI 全绿。

## 范围

**做**

1. 工程：Vite 8 + React 19 + React Compiler + TypeScript strict，ESLint、Prettier、Vitest、Playwright。目录按层分：`screens/`、`stores/`、`net/`、`audio/`（F-1 填）、`three/`（F-2 填）、`telemetry/`、`ui/`。
2. 类型只用 `packages/contracts` 生成的，不手写任何消息或响应的类型。
3. 路由：登录、封面、选身份、世界、结局（结局页先占位）；任何 401 或 WebSocket 4001 回登录，登录后回到原来的局。
4. 状态：zustand 的 `world` / `player` / `voice` / `ui` 四个 store，字段按 frontend-design 第 6 节；REST 数据用 TanStack Query。
5. 网络层：
   - REST：Cookie 鉴权；`/v1/me` 的 `activePlaythrough`；开局 409 时走「新しく始める」（先删再建）；错误按 api-contract 第 5 节映射成界面状态。
   - 一条 WebSocket：`hello { lastSeq }` → `welcome`；`commit` 按 `fromSeq..seq` 应用、去重、缺号时用 `GET /events?afterSeq=` 补；`turn_settled`；`ping` 每 20 秒；断线指数退避重连；不认识的消息类型忽略并计数（api-contract 0 节：只做加法）。
   - 收到的消息只写 store；组件不直接碰 socket。
6. 世界屏幕的 HUD 骨架（占位样式，视觉以后由 UX 的卡做）：`TextInput`、`Subtitles`（含 `source` 和「……」等待、`text: null` 的说明文字）、`SunBand`、`NearbyList`、`WorldReactionToast`、`ConnectionBanner`、`ResumeGate`。
7. 文字回合走通：`text { via: "typed" }` → `transcript` → `commit`（事件、记忆、叙述）→ `turn_settled`。
8. 遥测骨架：按 frontend-design 第 11 节批量发 `POST /v1/telemetry`；本卡只接 `screen_view` 和网络类指标，帧时间和语音指标由 F-1、F-2 接。
9. CI：类型检查、单元测试、Playwright 对 mock 跑上面「目标」那一轮、首屏 JS ≤ 120KB（brotli）超了就红。

**不做**

- 语音（F-1）、3D 场景和画质分级（F-2）、結局页正式版、記憶帳、連鎖反応マップ（M2 的卡）。
- UX 的视觉和日语文案定稿（用 mock 里的文案和占位样式）。

## 接口

全部来自 `packages/contracts`：api-contract 第 2 节各响应、3.2 客户端消息、3.3 服务端消息、第 5 节错误。Playwright 对 B-1 跑，B-1 回的每条消息 CI 里按同一套 Schema 校验。

## 验收

- `pnpm -F web test`、`pnpm -F web e2e`（对 `zoujin-mock`）全绿；命令以 R-0 定的为准。
- e2e 覆盖：登录、401 回登录、开局 409、文字一轮、断网 5 秒再连（补发不重复不丢）、不认识的消息类型不报错。
- 首屏 JS ≤ 120KB（brotli），CI 卡住。
- 组件里没有直接用 WebSocket 的地方（lint 规则或测试检查）。

## 禁止

不部署，不碰密钥和部署地址，不调真模型（只对 mock），不花钱，不加第三方监控脚本。

## 评审

后端看网络层和消息处理；UX 看屏幕流程和等待状态。

## 目标

世界屏幕里是 S7 的锡拉库萨广场（17:30 西南角第一屏），玩家能在广场上走（点地 / 摇杆，贴地、不穿墙），太阳按世界时钟走；画质按 D-019 分 L0〜L3，起始档靠进场时的加压自测，掉帧会降档。CI 卡场景资源体积和 draw call。

## 依据

- `docs/frontend/frontend-design.md` v1.0.1：第 8 节（3D 世界：场景 ID、加载、角色、镜头、光照和时钟）、10.1〜10.3（预算、加载、自适应画质）、10.6（写实定稿：10.6.2 两档规格和下载预算、10.6.3 起始档和升降档）
- `docs/ux/art-direction.md` v1.1：第 3 节（太阳就是时钟）、4.1（广场布局）、9.5（升降档时画面的要求）、第 10 节检查点 1、2
- S7 源码 `spikes/frontend/s7-realism/`（R-0 从项目文件夹 `frontend/spikes/s7-realism/` 搬来；`build/` 的 Blender 脚本、`page/index.html`）和它的 README（两个已修的坑：太阳高光溢出半精度、Sky.js 光盘过亮）
- `docs/pm/decisions.md` D-016、D-019

## 范围

**做**

1. 资产流水线进仓库：S7 的 `build_plaza.py`、`sky.py`、`sunpos.py`、`bake.py`、`encode.py` 和 gltf-transform 脚本放进 `assets/pipeline/`，一条命令生成广场的 glTF（meshopt）、KTX2 贴图、光照图、navmesh。生成物放哪按 2.1 的定（A-0 量完再定）。
2. `three/`：`SceneLoader`（按 `sceneRef` 加载，先能走再补细节）、`Lighting`（实时太阳 + 烘焙遮蔽 + 物理天空，跟 `world.clock` 走）、雾、后处理（泛光、调色、暗角，Neutral 色调映射）、`CameraRig`（第三人称、拖动转视角、对话时构图）、`Player`（navmesh 寻路和贴地）。人物先用 S7 的灰色假人（M2 换 A-0 的写实人物）。
3. 渲染器：T-002 有结果就用结果；没有就用 WebGLRenderer（S7 和 D-019 的数字都是它量的，包也小）。代码只用标准材质和少量自定义着色，两边都能跑。
4. 画质分级 L0〜L3（10.6.3）：离屏加压自测定起始档；每 5 秒看 p95，连续两次超预算降一级，马上生效的只有解像度；升档只在镜头切换和进出对话时；低电量（锁 30 帧）不升；高档资源到 L2 才在后台下。
5. 遥测：`perf_sample`（含 `qualityLevel`、`assetTier`、`lowPower`）、`quality_changed`（含 `probeGpuMs`、`assetMbps`）按 data-design 9.3。
6. 一个计测页（沿用 S7 的加压法），以后 S4、S5 和旧 iPhone 实测都用它，可以发成 claude.ai 私有页面在 iPhone 上开，不用部署。
7. CI：进场包 ≤ 8MB、场景环境合计 ≤ 10MB（高档 ≤ 19MB）、首次进入合计 ≤ 10MB、3D 分块 ≤ 250KB（WebGPU ≤ 380KB）、无头 Chromium 里数 draw call ≤ 120；两档贴图平均颜色一致（art-direction 9.5）。

**不做**

- 写实人物（A-0 之后的 M2 卡）、王座之间等其他场景（M3）、结局卡离屏渲染（M2 的卡）。
- 光照图精修和正式美术材质（等 UX 的风格指南 v1 和材质清单定稿）。

## 分几个 PR（D-023：一张卡一个 PR，大了就拆，顺序写在卡里）

1. **F-2a 资产流水线**：范围第 1 条和第 7 条里和场景资源有关的部分。`assets/pipeline/plaza/` 一条命令生成广场（几何、两档 KTX2 贴图、光照图、导航网格），`assets/scenes/syracuse-square/layout.json` 定可走区域、地点边界、位置点和出口，`scene.json` 清单进仓库，CI 查预算和两档颜色，并在干净环境里用草稿档从头跑一遍。生成物暂不进仓库：项目容器推 Git LFS 被网络策略挡住（`lfs.github.com`），能推之前在本地和 CI 现场生成。
2. **F-2b 世界屏幕**：范围第 2、3 条。`SceneLoader`、`Lighting`、雾、后处理、`CameraRig`、`Player`（读 `nav.json` 做 A* 和拉直、贴地，跨地点时调 store 的 move），本卡的假 store；验收里的 Playwright 截图、日没影子线、draw call、控制台无错误。
3. **F-2c 画质分级和计测**：范围第 4、5、6 条。L0〜L3、起始档自测、降档单元测试、遥测、计测页。
4. **F-2d 换成正式类型和 store**：C-1、F-0 合进 main 之后，删掉假类型和假 store。

## 接口

读 `world.clock`、`player.place / spot`、`characters[id].place / spot / activity`（store 的形状按 frontend-design 第 6 节）；玩家移动发 `action { kind: "move" }` 由 F-0 的网络层负责，本卡只调用 store 的方法。C-1、F-0 合进 main 之前，用本卡 `three/dev/` 下的假类型和假 store（只放上面这几个字段）；合进之后换成 `packages/contracts` 生成的类型和 F-0 的 store，删掉假的。

## 验收

- 生成脚本在干净环境里一条命令跑通，输出的大小在 CI 预算内。
- Playwright（无头 Chromium，软件渲染）：首屏截图和 S7 第三版第一屏（`shots/v2-sheet1.jpg`）构图一致；时钟从 18:00 推到 19:10，王城墙上的影子线往上走；draw call ≤ 120；控制台无错误。
- 降档逻辑的单元测试：喂假的帧时间序列，升降档的时机和次数符合 10.6.3。
- zg 的 iPhone 上开计测页，L1 / L2 的一帧 GPU 耗时和 S7 第二次实测同一量级（S7：b7 2.6ms）。**合并后补测，不挡 PR**：要 zg 拿手机看，经 PM 安排。

## 禁止

不部署，不碰密钥，不调模型，不花钱，不买素材。注意 S7 的石材贴图取自 Sponza 示例场景（要署名的授权，只适合验证），正式版换成 CC0 的扫描材质（Poly Haven、ambientCG 等），每张的来源、授权和 sha256 记在 `assets/` 的清单里；下载要在能访问这些网站的地方跑（项目容器现在访问不了，见 A-0）。

## 评审

UX 看画面（第一屏、日没的影子线、升降档那一下颜色不变）；后端看场景 ID 和移动的同步。

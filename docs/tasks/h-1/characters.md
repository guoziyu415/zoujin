## 修复与运行时接入

- 旧导出保留了转移 shape key 时的激活值，造成多种表情同时叠加。导出统一清零，运行时初始化再次归零，检查器拒绝非中性默认权重；嘴形与眨眼仍由原驱动控制。
- 衣服上下片改为按真实边界邻接顺序缝合，避免按角度排序连接到错误顶点。三角化后统一法线方向，并断言闭合边方向一致，修掉背部斜裂和反面消失。
- 裙摆与叠穿长袍使用一致的腰、腿权重，长袍下段随小腿；不再仅按最近皮肤分别传权重。旅人持布束、老人持杖的手臂姿势在导出动画里处理。
- 最终浏览器复核另修复新郎短披肩与内层衣服交叠、牧童短袍下皮肤穿出。梅洛斯原预制文件的衣服与眼部材质未通过检查，改为同样的完整重建流程，保留瘦长、羊毛短衣、凉鞋和行装设定，不再直接导出原型。
- 腰带与衣服使用一致的腰部绑定，缩小静态间距，避免躯干前倾时腰带悬浮。卫兵头盔改为圆顶；山贼蒙面布单独建连续曲面，不继承人体嘴部的孔洞。
- 保留面部细节；高档超预算时只简化过密服装拓扑。步行、普通对话、高档对话继续使用原来的独立预算。
- 群体代表从所属地点的真实 nav polygon 选位，避开玩家、普通 NPC 的当前点与目标点、已存在的群体代表及 F-4 群众。安全间距 1.4 米；没有位置则不显示，不叠到别人身上；玩家走近不会触发代表瞬移。结局演出期间探索层人物整体隐藏。
- 正式前端的角色静态目录只发布四类运行时 GLB，构建报告、原始 GLB、Blender 文件与 QA 图片不能通过角色静态路径读取；资产清单用于构建和部署校验。

## 可重复构建和本地证据

用 `assets/pipeline/cast/build.sh` 完整重建；设置 `MELOS_BLEND`、`UAL_GLB`、`BPY_PYTHON` 和 `CAST_QA_DIR`，含义和固定输入 hash 见脚本。Blender 为 bpy 5.2，MPFB 与动画库使用既有固定版本和来源。输入模型位于项目共享资料的 `frontend/spikes/a0-melos/mac/`，不进入 Git。

最终源文件与未压缩中间件保存在本机 `~/.zoujin/qa/h1-cast/release-source/`；运行资产在 `assets/cast/build/`。`cast.json` 保存各档字节、三角形、动画与 SHA-256。重建完成后运行：

```sh
node assets/pipeline/cast/check_cast.mjs assets/cast/build assets/cast/cast.json --require-all
CAST_QA_BROWSER_DIR="$HOME/.zoujin/qa/h1-cast/release-browser" node assets/pipeline/cast/qa_browser.mjs
```

浏览器检查只启动带随机密码的回环服务，实际解码压缩 GLB 并拍摄每套正面、背面、两段行走相位、斜前方行走、步行 LOD 背面与高档对话。不会上传资产或截图。静态角度检查不等同于逐帧布料仿真或真机帧率验证。

最终检查：17 套、68 个 GLB、119 张新鲜浏览器截图；全部源文件保留。独立读取 GLB accessor 核对三角形数、默认表情权重、SHA-256 和网页 dist 字节，全部一致。网页角色目录中非运行时文件为 0。最大值：步行 8000 三角形 / 310172 字节，普通对话 26612 / 2155508，高档对话 39989 / 2559724，动画 246284 字节；均在既有预算内。证据记录在本机 `release-verification.json`，不上传。

## 交叉审核

前端独立审查发现并要求修复：衣服边界环排序导致错误桥接、三角形绕序不一致、群体代表随玩家接近而挪位，以及与 F-4 群众重叠。总协调的画面审查要求修复旅人披风展开成硬片、帽冠头发穿出、后摆与腿绑定不协调。修复后统一全套重建，不能以中途截图或旧模型清单冒充最终结果。

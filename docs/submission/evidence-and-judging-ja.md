# 物語 の社会的価値と審査基準

物語 は、成人が文学作品に参加し、人物との関係や自分の選択を振り返るための体験を目指します。文学への入口を増やす価値と、実際の読書・理解への効果は区別して評価します。

## 読書に関する公式統計

文化庁の令和5年度調査では、1か月に本を読まないと回答した人は62.6%でした。その人たちの75.3%は、SNSやネット記事など本以外の文字情報をほぼ毎日読んでいます。書籍への接点を広げる余地を示す背景ですが、読書を嫌っている人の割合ではありません。

- 出典：[文化庁 令和5年度 国語に関する世論調査 結果の概要](https://www.bunka.go.jp/koho_hodo_oshirase/hodohappyo/pdf/94111701_02.pdf)、印刷ページ23–24（PDFの26–27ページ）。
- 調査時期：2024年1月16日–3月13日。対象は全国16歳以上の個人。有効回答3,559人。18–34歳だけの数値ではありません。
- 本には電子書籍を含み、雑誌・漫画を除きます。75.3%の分母は「読まない」と回答した人です。
- 古い調査との比較は調査方法変更の影響を受けます。[2025年度調査の公開項目](https://www.bunka.go.jp/tokei_hakusho_shuppan/tokeichosa/kokugo_yoronchosa/pdf/94441001_01.pdf)も確認しましたが、同じ読書設問の数値として扱える項目はありません。62.6%を2026年の最新実測値と表記しません。

## 文化と生涯学習の政策背景

[UNESCOの2024年文化芸術教育フレームワーク](https://www.unesco.org/sites/default/files/medias/fichiers/2024/02/WCCAE_UNESCO%20Framework_EN_0.pdf)は、成人を含む生涯学習、デジタル空間での文化参加、創造性や批判的思考、責任あるAI利用を位置づけています。物語 の成人向け文学体験を考える政策上の背景であり、製品の教育効果やUNESCOによる認定を意味しません。

## 製品で目指す価値と検証方法

| 目指す価値 | 現在の体験とのつながり | 今後確かめること |
| --- | --- | --- |
| 文学への新しい入口 | 3D空間と対話、原作を知らなくても読める導入 | 体験前後の原作への関心、実際に原作を読み始めたか |
| 人物の立場を想像する機会 | 人物ごとの知識・記憶・目的、対話による関係 | 複数人物の判断を、体験の具体例で説明できるか |
| 選択と責任の振り返り | 約束、保存された出来事、因果マップ、人物と自分の結末 | 自分の行動と後の出来事の関係を説明できるか |
| 自分なりの表現と参加 | 選択肢だけでなく自然な言葉で話す | 利用者が主体的に関われたと感じるか |
| 成人の文化的な学び直し | 学校で触れた作品や未読作品を、別の立場から経験する | 成人の既読・未読の両群で楽しさと理解を確かめる |

生成された出来事は原作の事実や唯一の正しい解釈ではありません。原作と生成体験の区別を明示し、本人の選択を道徳的な優劣として採点しません。現在は成人向け招待制の試作であり、学校導入、読書力向上、共感能力向上、治療効果を実証した製品とは扱いません。

## 第5回の審査基準との対応

公式の[第5回審査基準と提出条件](https://zenn.dev/hackathons/google-cloud-japan-ai-hackathon-vol5)は次の3項目です。公開ページには配点・重み・通過点の数値は記載されていません。以下は提出材料の対応整理であり、主催者の採点結果ではありません。

| 審査項目 | 提出物に含める説明と画面 |
| --- | --- |
| 課題の新規性と解決策の有効性 | 読書の公式統計、成人の文学参加という対象、人物との関係と個人の結末まで届く体験。効果は今後の検証として区別する。 |
| 自律性・エージェントらしさ | 入力を事件候補にし、規則と人物の知識・目的を検証して書き換え・拒否・確認を行い、世界を更新する処理。実際に保存された結果で示す。 |
| 実装品質と拡張性 | 実際の書斎・場面・人物、保存と再開、パスワードと招待制、Google Cloud構成、費用・失敗の記録。現在公開できる本は1冊であることも明示する。 |

## 公開範囲と実装範囲

製品コンセプト・説明・構成図・デモ動画の公開は許可済みです。実アプリは引き続きサイトパスワードと招待コードで保護します。認証情報は審査用の動作確認欄にのみ記載し、公開動画や図には含めません。

実装は React・Three.js、Cloud Runのゲートウェイと叙事者、Cloud SQL PostgreSQL、Gemini LiveとGeminiの文字応答、Model Armor、Claude、Secret Manager、Artifact Registryです。ADK、Firestore、Memory Bank、Veo、Cloud Trace exporterは現在の構成には含めません。図は主要経路を示し、ゲートウェイもClaudeを安全判定や発話候補の生成に利用します。

実音声はストリーミングされるため、全音声の発声前審査を保証しません。イベントや記憶の診断はありますが、全会話で記憶生成が成功する保証、全サイトの統一ハード予算、全量の結末・ネタバレ防止検証の達成は主張しません。

# 物語 3分デモの収録台本

約 3 分で、書斎から物語に入り、人物と話し、成立した出来事の記録を確認する流れを見せます。人物があなたを記憶する関係と、世界・人物・あなた自身の三層の結末を、実際に確認できる画面と機能の説明に分けて紹介します。全編を一局の完走にせず、実際のアプリ画面とモデルの応答を収録します。下の読み上げは説明用であり、人物の返答を指定する台詞ではありません。

録画とアップロードは利用者本人が行います。事前の確認は、文字入力で老爺に家まで送ると申し出た一往復です。老爺は断り、新しい約束の成立は確認していません。音声会話の収録は、これから利用者本人が行います。この台本も、同じ文を言えば必ず受け入れられるという成功手順ではありません。人物の知識や判断、実際に残った記録を紹介するための進行案です。

## 収録前の準備

- 認証済みの画面から録画を始めます。ブラウザのアドレス欄、パスワード、招待コード、開発者ツール、クラウドの管理画面は映しません。
- 実モデルを使う環境で、収録に使うプレイを確認します。用意済みの独立した第一幕のアカウントから、そのまま自由に会話を続けられます。下の例は市の広場の老爺との会話ですが、現在の状況に合わせて話題を選びます。既存の進行を消して撮り直す必要はありません。
- 音声会話の前にマイクを確認し、アプリの音と説明音声を別々に録れるようにします。人物が話している間は説明を重ねません。
- 発話後の処理が確定してから、イベントと画面に現れる結果を確認します。モデルが口頭で賛成しただけの場面を「世界が変わった」証拠にしません。約束、行動完了、記憶、関係の変化は、それぞれ実際の記録にある内容だけを紹介します。
- 下表の秒数は編集後の目安です。待ち時間を省く場合は「待機時間を一部省略」と表示し、応答速度を測った映像として扱いません。離れた時点の画面を、同じ操作の直後に起きたようにつなぎません。

## 実演で話す短い言葉

最初の質問は「この町では、何があったのですか。」を使えます。返答を聞いた後、状況に合えば「お家まで送りましょう。」と申し出ます。実際の返答に合わせて言葉を変え、人物が頼んでいないことを頼まれたように説明しません。

音声を使う場合は、実際の会話と処理結果を収録します。文字で会話する場合は、字幕を「文字の人物応答は Gemini」に変え、読み上げも「実際の文字での会話です」とします。文字入力の映像を音声対話の実証として扱いません。「家まで送る」専用ボタンがあることは前提にしません。処理確定の技術的な目印は `turn_settled` です。確認のために開発者ツールを使う場合も、それは公開映像に入れず、作品内の記録を映します。行動が拒否された場合はその結果を残し、台本に合わせてモデルの返事を書き換えません。

このやり取りでイベントが成立しなかった場合は、「この申し出から新しい出来事は成立しませんでした。返答があっても、世界が必ず変わるわけではありません。」と説明します。既存の実プレイに確認済みの記録があれば、「以前の実プレイの記録」と明示して見せられます。今回の発話の結果としてつなぎません。

イベントはあるが記憶がまだない場合は、「今回は出来事の記録までを確認しています。人物との記憶は、この記憶帳で振り返る構成です。」と説明します。約束が記録されていなければ「約束が成立した」とは言わず、記憶だけをもって「信頼が上がった」とも言いません。記憶や関係の変化を映像用に作りません。

拒否の返答を使う場合は、「今回は断られました。人物の判断があることは見えますが、この一往復だけで新しい関係や約束ができたとは言えません。」と添えられます。人物の記憶は保存されたものを確認し、全会話が永久に記憶されるとは説明しません。

## 回想録と未完了の扱い

収録アカウントに本当に保存済みの結末がある場合だけ、そのカードを数秒見せられます。別のプレイの結末を使う場合は「別のプレイで到達した結末」と添えます。三分の実演だけで、その結末まで進んだようには見せません。

完成した結末がなければ、空の回想録か途中の進行をそのまま見せます。その場合は「結末は世界、人物、あなた自身の三層です。このアカウントはまだ途中なので、今日は対話とその処理結果、続きから再開できるところまでを紹介しました。」に読み上げを置き換えます。サンプルの結末を捏造したり、映像用に完成済みとして登録したりしません。

## 三つの審査観点との対応

- **課題の新規性と解決策の有効性**：冒頭で成人読者と文学への入口を示し、会話と行動を体験として提示します。信頼や約束を考える機会は目標価値として述べ、読書量や共感性の向上を測定したとは言いません。
- **自律性・エージェントらしさ**：人物の声と目的、出来事から生まれる記憶、検証を経た世界の変化を見せます。短い実演に映らない不在人物の行動まで、今回動作を確認したようには語りません。
- **実装品質と拡張性**：保存されたイベント、途中からの再開、作品ごとの構成、Google Cloud 上の役割分担と安全上の境界を示します。現在の収録作品が一冊であることを隠しません。

文学的な学びとして説明するのは、人物ごとの立場を考え、自分の申し出と結果を振り返る機会です。原作を未読でも参加でき、体験から原作へ関心を持つ入口を目指します。効果の検証は今後、成人の既読・未読の両群で、人物の判断や選択の結果を説明できるか、原作を実際に読み始めたかを確かめます。三分の映像だけで理解力や共感性が向上したとは結論づけません。

## 書き出し前の確認

映像内の人物の返答、イベント名、行動結果が、同じプレイの実際の記録と一致していることを確かめます。字幕は原音を正確に写し、声を差し替えて別の発言にしません。速度や結果を一般化する数字、無限の結末、教育効果、200 局検証済み、ネタバレ完全防止といった説明は入れません。

公開用の図には、現行の Cloud Run、Gemini Live と Gemini の文字応答、Model Armor、Claude、Cloud SQL と必要な接続だけを載せます。アプリの入口は引き続きパスワードで保護し、動画はログイン済み画面から構成します。録画ファイルと YouTube への公開は、この台本の作成とは別の作業です。

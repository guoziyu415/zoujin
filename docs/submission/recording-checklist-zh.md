# 物語 (Monogatari) three-minute recording notes / 3分間録画のポイント

You are responsible for recording and uploading. The goal is to let the judges see literary participation, character memory, and the three-layer endings, along with a real Agent decision process; you do not need to play a full run within three minutes.

録画とアップロードはあなたの担当です。目的は、文学への参加、人物の記憶、三層の結末、そして実際のエージェントの判断過程を審査員に伝えることです。3分で一周を遊び切る必要はありません。

## Before recording / 録画前

Pass the password and invite code first, then start recording the web content. Do not record the address bar, login credentials, developer tools, or the cloud console. You may use existing play progress or a separate demo account; there is no need to clear any saves.

先にパスワードと招待コードを通過してから、ウェブ画面の録画を始めます。アドレスバー、ログイン認証情報、開発者ツール、クラウドコンソールは録画しないでください。既存のプレイ進行か別のデモアカウントを使ってよく、セーブを消す必要はありません。

First confirm that the characters, events, and memories you want to show actually exist. In the main thread's short trial recording, 老爺 refused the proposal to send him home. That was a real character reply; it was not verified that the proposal became an agreement, so you cannot claim he was sent home as in the script. You may respect the reply and keep talking, or show other actual records. Memory formation, rising relationship, and action success are three different outcomes.

見せたい人物、出来事、記憶が実際に存在することを先に確認してください。メインスレッドの短い試録では、老爺は家まで送るという提案を断りました。これは実際の人物の返答であり、提案が約束として成立したことは確認されていないため、台本どおり送り届けたと言うことはできません。返答を尊重して会話を続けても、他の実際の記録を見せても構いません。記憶の形成、関係の上昇、行動の成功は、それぞれ別の結果です。

## Export and upload / 書き出しとアップロード

Landscape, 1080p, about 3 minutes is recommended, with captions large enough to read on a phone. The architecture diagram is already 1920×1080. Do not spend the opening on password login or long walks.

横向き、1080p、約3分を推奨し、字幕はスマートフォンでも読める大きさにします。アーキテクチャ図はすでに 1920×1080 です。冒頭でパスワードログインや長い移動に時間を使わないでください。

Fill in the title and description using [youtube-metadata-ja.txt](youtube-metadata-ja.txt), set the video to public on YouTube, wait for processing to finish, and copy the actually playable video link. Before filling in the official contest form, check again that the video leaks no password, invite code, or address, and that the description matches the footage.

[youtube-metadata-ja.txt](youtube-metadata-ja.txt) でタイトルと説明を入力し、YouTube で公開に設定して処理完了を待ち、実際に再生できる動画リンクをコピーします。正式にコンテストのフォームへ入力する前に、動画にパスワード、招待コード、アドレスが映っていないこと、説明が映像と一致していることを再確認してください。

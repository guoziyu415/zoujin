# zoujin 三分钟录制要点

你负责录制和上传。目标是让评委看懂文学参与、人物记忆和三层结局，并看到一个真实的Agent判断过程；不必三分钟里玩完整局。

## 开录前

先通过密码和邀请码，再开始录制网页内容。不要录地址栏、登录凭证、开发者工具或云控制台。可使用原有试玩进度或独立演示账号，不必清空任何存档。

先确认想展示的角色、事件和记忆确实存在。主线程短试录时，老爺拒绝了送他回家的提议，这是一次真实人物回复；没有验证该提议成立为约定，不能照台本宣称已经送回家。你可以尊重回复继续交谈，也可以展示别的实际记录。记忆形成、关系上升和行动成功是三个不同结果。

## 镜头安排

| 时间 | 展示内容 |
| --- | --- |
| 0:00–0:25 | 书房与书架。说明成人文学入口：进入故事、与记得自己的角色交流互动。可用文化厅2023年度调查的62.6%与75.3%解释背景；后者只是不读书群体的比例。 |
| 0:25–0:40 | 当前仅『走れメロス』一本；展开「原作を読んでいない方へ」，证明不熟悉作品也能进入。 |
| 0:40–1:30 | 「近くの人」→人物→语音或「文字で話す」。用自己的话提问或行动；录下真实回答与处理结果。 |
| 1:30–2:05 | 「本をひらく」→「記憶帳」「連鎖反応マップ」。展示实际保存内容。若没有新事件，说明未成立；别拼接成成功。 |
| 2:05–2:35 | 展示架构PNG：Gemini人物对话→叙事者提取与规则检查→Cloud SQL保存；安全过滤与人物知识约束。 |
| 2:35–3:00 | 世界、各角色和你自己都有结局；展示真实完成局的回想，或说明当前账号尚未完成。回书房展示保存并继续体验。 |

日语旁白可用 [demo-script-ja.md](demo-script-ja.md)。文字实演就把“音声実演”换成“テキスト実演”；不要用配音冒充Gemini现场声音。角色说话时不叠讲解。等待剪短要标「待機時間を一部省略」，既往存档标「以前の実プレイ」，其他局结局标「別のプレイで到達した結末」。

## 出片与上传

建议横屏、1080p、约3分钟，字幕大到手机也能读。架构图已经是1920×1080。开头不要把时间花在密码登录或长距离走路上。

用 [youtube-metadata-ja.txt](youtube-metadata-ja.txt) 填标题和描述，在YouTube设为公开并等处理完成后，复制实际可播放的视频链接。正式填赛事表单前，再检查视频没有泄露密码、邀请码或地址，说明与画面一致。

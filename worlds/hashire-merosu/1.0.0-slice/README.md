# World model for the 『走れメロス』 slice (hashire-merosu@1.0.0-slice) / 『走れメロス』スライス版ワールドモデル（hashire-merosu@1.0.0-slice）

Owner: data engineering · Contract: `data/contracts.md` v1.15 · Basis: S-077 (`pm/decisions.md`), dev-plan "full world model + one slice config"

担当：データエンジニアリング · 契約：`data/contracts.md` v1.15 · 根拠：S-077（`pm/decisions.md`）、dev-plan「完全版ワールドモデル＋スライス設定 1 つ」

The world model for the M2 vertical slice (R1 playtest). It uses the same Schema as the full version, and B-0, worldsim and evals read it as is; it is **not hand-written** but generated by `make_slice.py` from `1.0.0-draft/world.src.json`. All differences between the slice and the full version live in that script, and each change notes which item of S-077 it comes from.

M2 縦スライス（R1 試遊）用のワールドモデル。完全版と同じ Schema を使い、B-0、worldsim、評価はそのまま読む。**手書きしない**：`make_slice.py` が `1.0.0-draft/world.src.json` から生成する。スライスと完全版の違いはすべてこのスクリプトにあり、各変更には S-077 のどの項目に由来するかを記す。

| File / ファイル | What it is / 内容 |
|---|---|
| `make_slice.py` | Generation script. **Edit only this file** (or the full version's authoring source) / 生成スクリプト。**このファイルだけを編集する**（または完全版の編集元） |
| `world.src.json` | Generated authoring source, read by build_world / 生成された編集元。build_world が読む |
| `world.json` | Generated by build_world: read by the backend at runtime / build_world が生成：バックエンドが実行時に読む |
| `report.md` | Validation report. Scenarios use the full version's `scenarios.json`, and the results of the 24 simulations should match the full version / 検証レポート。シナリオは完全版の `scenarios.json` を使い、24 回のシミュレーション結果は完全版と同じになるはず |

`bash .github/scripts/check_world.sh` regenerates and validates everything together (CI runs it too, and fails if the generated outputs differ from the repo).

`bash .github/scripts/check_world.sh` が再生成と検証をまとめて行う（CI でも実行され、生成物がリポジトリと異なれば失敗する）。

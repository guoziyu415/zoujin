## draft.3 改了什么（相对 draft.2）

- **按 PM 和 UX 的决定**：第 5 类底线结局（S-034）；幕名「約束の日／その夜／村の二日／三日目」和时刻标签「約束の日・夕方」（S-037）；第一幕从 17:30（夕方）开始，玩家先于梅洛斯到广场（UX 4.1）；「石工の見習い」改名「石屋の弟子」；旅人被押入王城时、石屋の弟子跟着师父时能进王城（`conditionalAccess`，UX 5.1）；时间消耗参数（S-038）。
- **D-012、D-013 的落地**：7 个人物的互助、约定模板、每幕打算，能对上原文的都附了出处（S-029、S-030、S-048）。
- **情境动作**：第四幕河边、山口、泉边、进城的路每处一个「让他慢」一个「帮他快」（S-036 ②）；身份独有的动作 4 个（UX 5.1）；第三幕帮着备婚礼 2 个。按钮文字只写动作，耗时另给，前端拼成「引き止める（三十分ほど）」。
- **给后端和前端的**：节拍上的人物状态（`activities`，前端的 idle / walk / run / talk / work / sleep）、开局在做什么；台词和动机的生效时间（例：王的「どうか、わしをも仲間に入れてくれまいか」只在改心之后进提示，免得提前说出来）。
- **时间规则修了两处**（契约 2.4.1、2.5.1 已写清）：
  1. 「力尽きる」这类决定后面时间的节拍，到点前提不成立就当场记为没发生，省下的 60 分钟马上退还。
  2. 洪水冲桥是渡河的前提，但不是同一条时间线（`edge.17-18` 标 `timeLink: order`）。以前第三幕帮梅洛斯省下的时间被洪水的「0 偏移」卡住，传不到第四幕；现在能传到。
- **随身的东西**（契约 1.3，UX 5.1）：旅人带革の水袋和旅の外套，石屋の弟子带鑿和工房の鍵，牧童带革の水袋和羊飼いの杖；妹妹给弁当、花婿借灯（`MutualAid.gives`）；梅洛斯的短剑在捕缚时被没收（`beat.04` 的 `hold`，出处「調べられて、メロスの懐中からは短剣が出て来た」），玩家拿不到。
- **旅人进王城**改成 UX 5.1 的写法：梅洛斯被捕时旅人在他身边，就作为「連れの者」一起被带进去，不绑（`conditionalAccess`：同行 + 梅洛斯被捕）；自己惹事被捕时也能进。
- 新增 `edge.20-21-delay`（倒下睡着耽误 60 分钟，出处「四肢を投げ出して、うとうと、まどろんでしまった。」）。

## 契约 1.4 改了什么（UX 校对 `ux/reviews/data-world-draft3.md`、PM 的 S-064）

- **セリヌンティウスの疑い（S-064）**：新节拍 `beat.s2`「ちらと友を疑う」（三日目 16:00 前后，时刻推定，出处「たった一度だけ、ちらと君を疑った」）。前提是人质的支撑 `var.selinuntius.faith` ≤ 2。弟子的「親方のそばにいる」+2（一局一次），再加「自分の目で見たメロスの様子を届ける」或「一緒に信じ続ける」+1，到 3 就不疑。只是陪着不够；说让他疑的话、违背「そばにいる」的约定可以 −1。
- **刑场的殴り合い（beat.25）有三种演法**（契约 1.4 `Beat.variants`）：两人都没疑过 → 不打，只抱；只有梅洛斯疑过 → 只有梅洛斯挨打；只有塞利农提乌斯疑过 → 只有他挨打。梅洛斯疑没疑由 `beat.20`（倒下）决定。人质是玩家时不演这一场。`beat.s2` 进了结局署名。
- **第三幕**：「帮花婿备婚礼」只改花婿（不用梅洛斯通宵说服，婚礼仍在正午，出发不变，UX 1.1）；早出发改成新动作「夜明け前にメロスを起こす」（出发早 60 分，出处「寝過したか」「悠々と身仕度」）。
- **过场二选一**（`ActExit.enRoute`，UX 3.2）：跟梅洛斯冲进雨里时，过场页给「隣村で、メロスは歩をゆるめた。」〔急かす〕〔好きにさせる〕。急かす = 早 40 分到河边，体力照样消耗。
- **第四幕按钮**写对梅洛斯的影响（`melosMinutes`，UX 4.3）：校验工具用共享规则逐个核对。近道只给牧童，别的身份要先从花婿那里听说（`aid.groom.shortcut`）；新增「先に走って知らせる」（刑场早 5 分，不动期限）。
- **修了两处隐性问题**：① 路上节拍的最早时间截住了「帮他快」（例：叫醒早 60 分只早到 40 分），已放宽，改成明确的到达下限 17:30（`clock.deadline.earliestArrival`，S-066：超过下限的部分作废，拖慢照算全额；按钮显示本局实际值，共享规则 `arrival_delta`）；② 过场「急かす」以前连体力也省了，一次点击早到 100 分；`edge.21-24` 改成只管先后，进城路上省的时间才传得到刑场。
- **人物**：塞利农提乌斯 4 句设计台词（UX 2.1）、「警吏の前であなたをかばう」写清时机（2.2）、王的赌约语气（2.4）和「ならば、おまえも人質になるか」（1.2）、花婿的「大事」条件（2.6）、フィロストラトス第二、三幕的打算（2.7）、老爺的语尾和两句台词（2.8）；全局规则加「不回应恋爱」（2.5）；王的信任阈值写进 `var.king.trust`（1.2）；旅人的说明改成「メロスの連れとして」（3.1）；梅洛斯的衣服改成「メロスの衣は、ほとんど裂けていた」（3.5）。

## 契约 1.5 改了什么（UX 复核，`ux/reviews/data-world-draft3.md` 第 7 节）

- **山口**（UX 7.4，选了方案 A，再补一条人人可用的）：
  - 绕开山口的脇道只给牧童，别的身份要先从花婿那里听说村和市之间的抜け道（`aid.groom.shortcut` 现在包括峠の脇道）。按钮改为「峠を避けて、脇道を行く」，不写「山賊」。
  - 人人可用的「帮他快」改成「先に登って様子を見る」：你先登上去，发现埋伏的人，提醒他，早 10 分钟。三个人照打，体力照样耗，过了山口照样倒下、照样怀疑，刑场照原作互殴（`sc.pass-scout`）。
  - 为此 `edge.18-20`（激流 → 倒下）改成只管先后：倒下的时刻只跟山口走，山口早了它也早。其他情景的结果都没变。
- **セリヌンティウス的台词**（UX 7.1）：工房那句拆成两句，「手を止めるな。日が落ちる前に、ここまでは刻んでおきたい。」只到日没（`beat.02`），「……城の方が、やけに騒がしいな。」从梅洛斯被捕到他被召；刑场那句改为「メロス、私は一度も君を疑わなかった。……ひとりで待っていたのでは、なかったからな。」，并限定在弟子陪过他的局。
- **过场二选一**（UX 4.5）：「急かす」的按钮带分钟数（`melosMinutes` −40，构建时核对），选了以后多一句「メロスは足を速めた。河原には、思ったより早く着いた。」（`after`）。
- **结局**：「間に合わなかった」和「あなたが身代わりになった」的说明改为不写「処刑」，指向 ux-design 11.4 的文案（S-067）。
- **到达下限改为逐步算**：到了 17:30 再帮快是 0，拖慢照算，拖慢之后再帮快最多回到 17:30（和 ux-design 4.3 一致；1.4 的写法让拖慢之后的帮快也是 0）。第一次到下限时说的一句放进世界模型（`clock.deadline.earliestArrivalCue`：梅洛斯在场说「……これなら、間に合う。」，不在场叙事说「この足なら、陽の沈む前に着く。」）。
- 评测加 `E5-017`（山口先登上去看看）、`E5-018`（到下限后被拖慢再递水）、`E7-011` 和模拟画像 `persona.melos-helper`；模拟局另统计 `beat.25` 四种演法的比例（UX 7.5）。

## 和交接文档不同的地方（已对照原文）

1. **婚礼在 Day 2 正午**，不是到村当天。梅洛斯 Day 1 上午到村，睡到夜里，整夜说服花婿到天亮（S-011 已定）。
2. **山贼是「一隊」**，梅洛斯打倒其中三个（「三人を殴り倒し」），交接文档写的是「三个山贼」。
3. **フィロストラトス是塞利农提乌斯的弟子**（「セリヌンティウス様の弟子」），和身份「石屋の弟子」重叠。草案把身份设为他的师弟（UX 5.1 沿用）。
4. **王的耳语只有梅洛斯听到**（「ちょっとおくれて来るがいい」）。第二版的「王城の侍女」可以设计成唯一能偷听到的人。
5. **「王派了山贼」只是梅洛斯的猜测**，原文没有证实；世界模型里是梅洛斯的私有想法（`fact.melos-suspects-king`），不是事实。
6. **梅洛斯正午到河边**（「太陽も既に真昼時です」）；原著里他在日没那一刻冲进刑场，**时间余量是零**（S-036 保持）。
